# HCL UI Interview Prep Revision

Round themes:

* Container With Most Water
* Roman to Integer
* React 1000+ records optimization
* auth, JWT, sessions, protected routes, CORS
* `call`, `apply`, `bind`
* async/await vs Promises
* Webpack/build tools
* React code review and optimization
* sorted/nested boxes machine-coding task

Short answers:

* `call`: invoke now, pass args individually.
* `apply`: invoke now, pass args as array.
* `bind`: return a new function for later.
* For 1000+ records: paginate, debounce search, virtualize, memoize, handle loading/error/empty states.
* For auth: frontend route guards help UX; backend token validation is mandatory.
* For async: use `async/await` for readability, `Promise.all` for parallel work.
