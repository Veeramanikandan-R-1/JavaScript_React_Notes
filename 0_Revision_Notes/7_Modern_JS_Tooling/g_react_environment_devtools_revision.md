# Revision Notes: React Environment Variables and DevTools

## Environment Variables

CRA:

```text
REACT_APP_API_URL=https://api.example.com
```

Vite:

```text
VITE_API_URL=https://api.example.com
```

Never store secrets in frontend env vars.
