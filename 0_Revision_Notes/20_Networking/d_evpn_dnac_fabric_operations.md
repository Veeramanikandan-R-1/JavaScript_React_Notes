# EVPN DNAC Fabric Operations Revision

Fabric roles:

| Role | Meaning |
| ---- | ------- |
| Leaf | endpoint access and VTEP |
| Spine | underlay transit between leaves |
| Border leaf | external network handoff |
| Border spine | spine with border role in some designs |

Must know:

* BUM = Broadcast, Unknown unicast, Multicast.
* MDT/BUM pools relate to multicast replication for BUM traffic.
* Border handoff connects EVPN fabric to external L2/L3 domains.
* DNAC centralizes automation, assurance, policy, and operations.
* EVPN is more standards/fabric-overlay focused.
* SDA is more campus policy/automation focused.
