# Networking Foundations Revision

* L2 switching forwards frames using MAC addresses.
* Switches learn source MAC -> port mappings in the CAM table.
* Unknown destination MACs are flooded within the VLAN.
* VLANs create separate broadcast domains.
* Access port: one VLAN.
* Trunk port: multiple VLANs with tagging.
* SDN separates control plane and data plane.
* Zero Trust SD-Access verifies identity and applies least-privilege policy.
* SLAAC lets IPv6 devices auto-configure addresses.

Shortcut:

```text
VLAN = segmentation
SDN = programmable centralized control
SD-Access = Cisco policy/automation fabric for campus
Zero Trust = never trust, always verify
```
