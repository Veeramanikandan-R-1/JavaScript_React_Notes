# Revision Notes: React Revision and Interview Notes

## Basics

* React builds reusable UI components.
* Functional components with hooks are the modern standard.
* JSX compiles to JavaScript.
* Props come from parent.
* State belongs to the component and causes re-render.
* React was created by Jordan Walke at Facebook and open-sourced in 2013.
* Check official React release notes for current/latest version details.

---

# JSX Rules

* one root element or fragment
* close all tags
* use `className`
* expressions inside `{}`
* camelCase attributes
