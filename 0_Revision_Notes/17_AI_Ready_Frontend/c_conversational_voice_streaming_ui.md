# Revision Notes: Conversational, Voice, and Streaming AI UI

## Chat UI Needs

* Message list
* Input
* Send button
* Loading/streaming indicator
* Stop button
* Retry
* Copy response
* Regenerate

---

# Voice UI Needs

* Speech-to-text
* Text-to-speech
* Microphone permission handling
* Text fallback
* Accessible controls

---

# Common Mistakes

* No stop button
* No error state
* Losing scroll position
* Voice-only UI
* Constant focus stealing during streaming
