# Modern React 19 Revision

## Must Know

* Actions structure async mutation flows.
* `useActionState` connects an Action result to component state.
* `useFormStatus` reads nearest parent form pending status.
* `useOptimistic` shows temporary UI before the server confirms.
* `use` can read promises/context in supported React environments.
* `useEffectEvent` separates non-reactive Effect logic.
* React Compiler provides automatic memoization at build time.

## Interview Lines

* Actions help model pending, success, error, and validation states.
* Optimistic UI needs rollback and server reconciliation.
* React Compiler reduces manual memoization pressure, but pure rendering and React rules become even more important.
