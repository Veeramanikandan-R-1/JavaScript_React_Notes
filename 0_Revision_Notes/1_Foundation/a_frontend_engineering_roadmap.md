# Revision Notes: Frontend Engineering Roadmap

## What to Remember

Frontend development means building what users see and use in the browser.

```text
HTML -> structure
CSS -> design and layout
JavaScript -> behavior
React -> reusable UI components
Git -> version control
DevTools -> debugging
```

---

# Learning Order

```text
1. HTML
2. CSS
3. JavaScript
4. DOM and events
5. Async and fetch
6. Git
7. React
8. Routing, forms, testing, performance
```

---

# Practice Checklist

* Build a profile page.
* Build a contact form.
* Build a responsive navbar.
* Build a todo app.
* Build an API data loader.
* Build a React product list.

---

# Common Mistakes

* Starting React before HTML/CSS/JS basics.
* Reading too much without building.
* Ignoring DevTools.
* Testing only desktop layout.
* Not using Git branches.

---

# Interview Quick Answers

### What should a frontend developer know first?

HTML, CSS, JavaScript, browser basics, Git, and debugging.

### Why learn basics before React?

React still depends on HTML, CSS, JavaScript, events, forms, and browser behavior.

### How do you improve quickly?

Build small features, debug them, rewrite them, and explain them clearly.
