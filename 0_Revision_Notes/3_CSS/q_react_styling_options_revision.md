# Added from `react_1.docx`

* SCSS is transpiled into normal CSS.
* Useful SCSS features include variables, nesting, mixins, functions, partials, and imports.
* SCSS can improve reuse and organization in larger codebases.
* Watch for over-nesting and unnecessary build complexity.
* Ant Design is another common enterprise React UI library.
* StyleX is a compile-time atomic CSS approach associated with Meta-style architecture.
