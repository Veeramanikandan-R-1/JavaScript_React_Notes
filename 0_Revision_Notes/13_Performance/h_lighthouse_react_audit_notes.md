# Lighthouse React Audit Revision

Lighthouse categories:

* Performance
* Accessibility
* Best Practices
* SEO
* PWA

Metrics:

| Metric | Meaning |
| ------ | ------- |
| FCP | first visible content |
| LCP | main/largest content visible |
| CLS | visual stability |
| TBT | main-thread blocking during load |
| Speed Index | visual loading speed |

React fixes:

* code-split routes
* lazy-load heavy components
* reduce bundle size
* optimize images and fonts
* use semantic HTML and labels
* add manifest/service worker for PWA checks

Lighthouse is lab/synthetic. Core Web Vitals can come from real-user field data.
