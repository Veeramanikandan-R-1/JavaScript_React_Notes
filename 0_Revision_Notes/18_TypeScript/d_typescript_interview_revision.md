# Revision Notes: TypeScript Interview Revision

## Fast Answer

TypeScript adds static typing to JavaScript. It improves reliability, autocomplete, refactoring, and maintainability, especially in large React apps. It still compiles to JavaScript and does not replace runtime validation.

## Must Explain

* `any` vs `unknown`
* `void` vs `never`
* `type` vs `interface`
* union vs intersection
* generics
* utility types
* type narrowing
* `keyof` and `typeof`
* React props, state, events, refs, context, reducers, and API responses
