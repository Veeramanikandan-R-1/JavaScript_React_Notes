## Regex (Regular Expression)

**Regex** is a pattern used to **search, match, validate, extract, or replace text**.

In React/JavaScript, Regex is commonly used for **form validation, input filtering, searching, and parsing**.

### 1. Basic Syntax

```js
const regex = /pattern/flags;
```

Example:

```js
const regex = /^[A-Za-z]+$/;

console.log(regex.test("John")); // true
console.log(regex.test("John123")); // false
```

`test()` returns `true`/`false`.

---

### 2. Important Regex Characters

| Pattern | Meaning                      | Example              |
| ------- | ---------------------------- | -------------------- |
| `.`     | Any character except newline | `a.c` → `abc`, `a1c` |
| `^`     | Start of string              | `^Hello`             |
| `$`     | End of string                | `World$`             |
| `*`     | 0 or more                    | `a*`                 |
| `+`     | 1 or more                    | `a+`                 |
| `?`     | 0 or 1                       | `a?`                 |
| `{n}`   | Exactly n times              | `\d{4}`              |
| `{n,}`  | At least n times             | `\d{2,}`             |
| `{n,m}` | Between n and m              | `\d{2,4}`            |
| `\d`    | Digit `0-9`                  | `\d+`                |
| `\D`    | Non-digit                    | `\D+`                |
| `\w`    | Letter, digit, `_`           | `\w+`                |
| `\W`    | Non-word character           | `\W`                 |
| `\s`    | Whitespace                   | `\s+`                |
| `\S`    | Non-whitespace               | `\S+`                |

---

### 3. Character Sets

```js
[abc]
```

Matches **a OR b OR c**.

```js
[0-9]
```

Matches any digit.

```js
[A-Za-z]
```

Matches any English letter.

Negation:

```js
[^0-9]
```

Matches anything **except digits**.

---

### 4. Groups and OR

`()` → capturing group

```js
/(cat|dog)/
```

Matches either `cat` or `dog`.

```js
const regex = /^(cat|dog)$/;

regex.test("cat"); // true
regex.test("dog"); // true
regex.test("cow"); // false
```

`|` means **OR**.

---

### 5. Common React Form Validation

**Email:**

```js
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

emailRegex.test("user@example.com"); // true
```

**Phone number (10 digits):**

```js
const phoneRegex = /^\d{10}$/;

phoneRegex.test("9876543210"); // true
phoneRegex.test("98765");      // false
```

**Password: minimum 8 chars, uppercase, lowercase, digit:**

```js
const passwordRegex = /^(?=.*[A-Z])(?=.*[a-z])(?=.*\d).{8,}$/;

passwordRegex.test("Hello123"); // true
```

Here:

* `(?=.*[A-Z])` → at least one uppercase
* `(?=.*[a-z])` → at least one lowercase
* `(?=.*\d)` → at least one digit
* `.{8,}` → minimum 8 characters
* `^...$` → entire string must satisfy the pattern

---

### 6. Regex Methods in JavaScript

#### `test()`

Returns boolean:

```js
/\d+/.test("abc123"); // true
```

#### `match()`

Returns matched values:

```js
"Order 123 and 456".match(/\d+/g);
// ["123", "456"]
```

#### `replace()`

```js
"hello world".replace(/world/, "React");
// "hello React"
```

#### `search()`

Returns index:

```js
"Hello123".search(/\d/);
// 5
```

---

### 7. Important Flags

```js
/pattern/flags
```

| Flag | Meaning                   |
| ---- | ------------------------- |
| `g`  | Global — find all matches |
| `i`  | Case-insensitive          |
| `m`  | Multiline                 |
| `s`  | `.` matches newline       |
| `u`  | Unicode                   |
| `y`  | Sticky matching           |

Example:

```js
"Hello hello".match(/hello/gi);
// ["Hello", "hello"]
```

Without `g`, only the first match is returned by `match()`.

---

### 8. Lookahead — Important for Validation

Lookahead checks a condition **without consuming characters**.

```js
/^(?=.*\d).+$/
```

Means: the string must contain **at least one digit**.

Negative lookahead:

```js
/^(?!.*password).+$/
```

Means: string must **not contain `password`**.

---

### 9. Escaping Special Characters

Characters like `.`, `+`, `*`, `?`, `(`, `)` have special meanings.

To match them literally, escape with `\`.

```js
/\./
```

matches an actual `.`.

Example:

```js
"file.txt".match(/\./);
// ["."]
```

---

### 10. Regex in React

Typical usage:

```jsx
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

function handleSubmit(e) {
  e.preventDefault();

  if (!emailRegex.test(email)) {
    setError("Invalid email");
    return;
  }

  // submit form
}
```

### Interview Must-Know

For a **5-year React developer**, know these particularly well:

* `^` and `$`
* Character classes: `[]`, `[^]`
* Quantifiers: `*`, `+`, `?`, `{n,m}`
* `\d`, `\w`, `\s`
* Groups `()`
* OR `|`
* Lookahead `(?=...)`, `(?!...)`
* Flags: `g`, `i`, `m`
* `test()`, `match()`, `replace()`, `search()`
* Common form validations
* Difference between **capturing groups `()`** and **non-capturing groups `(?:)`**
* Regex is for **pattern matching**, not a replacement for proper server-side validation.
