Given a non-empty array of integers nums, every element appears twice except for one. Find that single one.

You must implement a solution with a linear runtime complexity and use only constant extra space.

 

Example 1:

Input: nums = [2,2,1]

Output: 1

Example 2:

Input: nums = [4,1,2,1,2]

Output: 4

Example 3:

Input: nums = [1]

Output: 1

 

Constraints:

1 <= nums.length <= 3 * 104
-3 * 104 <= nums[i] <= 3 * 104
Each element in the array appears twice except for one element which appears only once.

## my solution

```js
/**
 * @param {number[]} nums
 * @return {number}
 */
var singleNumber = function(nums) {
    let result = null;
    for(let i =0; i < nums.length; i++){
        let isDuplicate = false;
        for(let j =0; j < nums.length; j++){
            if(i!==j && nums[i]===nums[j]){
                isDuplicate = true;
                break;
            }
        }
        if(!isDuplicate){
            result = nums[i];
        }
    }
    return result;
};

```

## optimized

Your solution is **correct**, but it is **not optimized** for the required constraints.

### 1. Problem with your solution

You have a nested loop:

```js
for (let i = 0; i < nums.length; i++) {
    for (let j = 0; j < nums.length; j++) {
        ...
    }
}
```

For every element, you're potentially checking the entire array.

So:

* **Time:** `O(n²)` ❌
* **Space:** `O(1)` ✅

But LeetCode explicitly requires **linear runtime `O(n)`**.

## 2. Best solution: XOR

The key observation is the **XOR (`^`) operator**.

Important XOR properties:

```text
a ^ a = 0
a ^ 0 = a
```

Therefore, if we XOR everything:

```text
[4, 1, 2, 1, 2]

4 ^ 1 ^ 2 ^ 1 ^ 2

= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4
```

### JavaScript solution

```js
var singleNumber = function(nums) {
    let result = 0;

    for (const num of nums) {
        result ^= num;
    }

    return result;
};
```

### Complexity

```text
Time:  O(n)     ✅
Space: O(1)     ✅
```

This is the **optimal solution** for this problem.

---

## 3. Why XOR works here

Suppose:

```js
nums = [2, 2, 1]
```

Execution:

```text
result = 0

0 ^ 2 = 2
2 ^ 2 = 0
0 ^ 1 = 1
```

Answer:

```text
1
```

Another example:

```text
[4, 1, 2, 1, 2]

0 ^ 4 = 4
4 ^ 1 = 5
5 ^ 2 = 7
7 ^ 1 = 6
6 ^ 2 = 4
```

Answer:

```text
4
```

### Interview takeaway

When you see:

> **Every number appears twice except one**

immediately think:

**XOR**

because:

```text
duplicate ^ duplicate = 0
0 ^ single = single
```

Your nested-loop approach demonstrates the basic idea of finding duplicates, but for this specific problem, **XOR is the expected interview-level solution**.
