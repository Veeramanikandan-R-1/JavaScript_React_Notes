# Zustand (Basics)

## What is Zustand?

Zustand is a **lightweight state management library** for React. It lets you create a **global store** without needing Providers, reducers, or actions like Redux.

> Think of it as **"useState for global state."**

---

## Installation

```bash
npm install zustand
```

---

## Create a Store

```javascript
import { create } from "zustand";

const useCounterStore = create((set) => ({
  count: 0,

  increment: () =>
    set((state) => ({
      count: state.count + 1
    })),

  decrement: () =>
    set((state) => ({
      count: state.count - 1
    }))
}));
```

---

## Use the Store

```javascript
function Counter() {
  const { count, increment } = useCounterStore();

  return (
    <>
      <h2>{count}</h2>
      <button onClick={increment}>+</button>
    </>
  );
}
```

---

## Advantages

* Very small (~2 KB)
* Minimal boilerplate
* No Provider required
* Easy to learn
* Good performance (components subscribe only to selected state)

---

## When to use?

* Small to medium React applications
* Simple global state
* Replacing Context API or Redux for less complex apps

---

## Limitations

* Smaller ecosystem than Redux
* Fewer built-in tools for complex enterprise apps

---

# Recoil (Basics)

## What is Recoil?

Recoil is a **React state management library** developed by Meta (Facebook).

It manages global state using **Atoms** and **Selectors**.

---

## Installation

```bash
npm install recoil
```

---

## RecoilRoot

Wrap your app:

```jsx
import { RecoilRoot } from "recoil";

<RecoilRoot>
  <App />
</RecoilRoot>
```

---

## Atom

An **Atom** is a piece of global state.

```javascript
import { atom } from "recoil";

export const counterState = atom({
  key: "counter",
  default: 0
});
```

---

## Using an Atom

```javascript
import { useRecoilState } from "recoil";

function Counter() {
  const [count, setCount] = useRecoilState(counterState);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}
```

---

## Selector

A **Selector** derives or computes state from atoms.

```javascript
const doubleCount = selector({
  key: "doubleCount",

  get: ({ get }) => {
    return get(counterState) * 2;
  }
});
```

Use it:

```javascript
const value = useRecoilValue(doubleCount);
```

---

## Advantages

* Simple API
* Great support for derived state (Selectors)
* Fine-grained updates (only affected components re-render)
* Feels similar to React Hooks

---

## Limitations

* Requires `RecoilRoot`
* Smaller ecosystem than Redux
* Development has slowed, so adoption is lower compared to Redux Toolkit and Zustand

---

# Zustand vs Recoil vs Redux Toolkit

| Feature           | Redux Toolkit                 | Zustand           | Recoil                     |
| ----------------- | ----------------------------- | ----------------- | -------------------------- |
| Boilerplate       | Medium                        | Very Low          | Low                        |
| Learning Curve    | Medium                        | Easy              | Easy                       |
| Provider Required | Yes (`Provider`)              | No                | Yes (`RecoilRoot`)         |
| Async Support     | `createAsyncThunk`, RTK Query | Manual            | Manual                     |
| Best For          | Large enterprise apps         | Small/Medium apps | Apps needing derived state |
| Ecosystem         | Excellent                     | Good              | Smaller                    |

---

# Which one should you use?

* **Redux Toolkit** → Large enterprise applications with complex state and API management.
* **Zustand** → Small to medium applications where you want a simple global store.
* **Recoil** → Applications that benefit from derived state using atoms/selectors, though it's less commonly chosen today.

# Common Interview Questions

### 1. Why would you choose Zustand over Redux?

**Answer:** Zustand has much less boilerplate, no Provider, and is ideal for simple global state. Redux Toolkit is a better choice for large applications with complex state management and middleware needs.

---

### 2. What is an Atom in Recoil?

**Answer:** An Atom is the smallest unit of global state. Components can subscribe to it and re-render only when that atom changes.

---

### 3. What is a Selector in Recoil?

**Answer:** A Selector computes derived state from one or more atoms. It's similar to memoized selectors in Redux.

---

### 4. Does Zustand require a Provider?

**Answer:** No. Zustand stores are accessed directly through custom hooks created with `create()`.

---

### 5. Which state management library is most commonly used in enterprise React projects?

**Answer:** **Redux Toolkit** is still the most common choice for enterprise applications because of its mature ecosystem, predictable architecture, excellent DevTools support, middleware, and built-in RTK Query for API state management.
