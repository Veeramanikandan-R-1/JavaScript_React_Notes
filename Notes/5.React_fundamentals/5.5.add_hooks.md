# React JS — Additional Hooks

These are **less commonly used Hooks**. For a 5-year React interview, know the **purpose + basic usage + when to use**.

---

## 1. `useId`

Generates a **unique, stable ID** for accessibility and associating HTML elements.

```jsx
function EmailInput() {
  const id = useId();

  return (
    <>
      <label htmlFor={id}>Email</label>
      <input id={id} />
    </>
  );
}
```

**Use for:** `label` ↔ `input`, `aria-describedby`, etc.

> ❌ Don't use `useId()` for list keys. Use a data ID.

---

## 2. `useTransition`

Marks a state update as **non-urgent**, allowing urgent UI updates to remain responsive.

```jsx
function Search() {
  const [query, setQuery] = useState("");
  const [isPending, startTransition] = useTransition();

  const handleChange = (e) => {
    setQuery(e.target.value);

    startTransition(() => {
      // expensive UI update
    });
  };

  return (
    <>
      <input onChange={handleChange} />
      {isPending && <p>Loading...</p>}
    </>
  );
}
```

**Use for:** expensive rendering such as filtering large lists, tab switching, etc.

> It doesn't make the expensive work faster; it tells React that the update has lower priority.

---

## 3. `useDeferredValue`

Creates a **deferred version of a value** so expensive UI can update later.

```jsx
function SearchResults({ query }) {
  const deferredQuery = useDeferredValue(query);

  return <Results query={deferredQuery} />;
}
```

**Use for:** keeping an input responsive while expensive results render.

### Remember

```text
useTransition
→ defer a state update

useDeferredValue
→ defer a value
```

---

## 4. `useLayoutEffect`

Similar to `useEffect`, but runs **after DOM changes and before browser paint**.

```jsx
function Box() {
  const ref = useRef();

  useLayoutEffect(() => {
    console.log(ref.current.getBoundingClientRect());
  }, []);

  return <div ref={ref}>Hello</div>;
}
```

**Use for:** DOM measurement, positioning, layout calculations.

```text
Render
  ↓
DOM update
  ↓
useLayoutEffect
  ↓
Browser paint
  ↓
useEffect
```

> Use `useEffect` by default. Use `useLayoutEffect` when work must happen before paint.

---

## 5. `useImperativeHandle`

Controls **what a parent can access through a child's ref**.

```jsx
const Input = forwardRef((props, ref) => {
  const inputRef = useRef();

  useImperativeHandle(ref, () => ({
    focus: () => inputRef.current.focus()
  }));

  return <input ref={inputRef} />;
});
```

Parent:

```jsx
const ref = useRef();

<Input ref={ref} />

ref.current.focus();
```

**Use for:** exposing imperative actions like `focus()`, `scroll()`, `play()`, etc.

> Prefer normal props/callbacks where possible.

---

## 6. `useSyncExternalStore`

Used to **subscribe to data/state that exists outside React**.

```jsx
function subscribe(callback) {
  window.addEventListener("online", callback);

  return () => {
    window.removeEventListener("online", callback);
  };
}

function getSnapshot() {
  return navigator.onLine;
}

function Status() {
  const online = useSyncExternalStore(
    subscribe,
    getSnapshot
  );

  return <p>{online ? "Online" : "Offline"}</p>;
}
```

**Use for:**

* External state stores
* Browser APIs
* Third-party stores

> For normal React state, use `useState`/`useReducer`.

---

## 7. `useInsertionEffect`

A specialized Hook mainly used by **CSS-in-JS libraries** to insert styles before layout effects run.

```jsx
useInsertionEffect(() => {
  // Insert CSS
}, []);
```

Conceptually:

```text
DOM update
   ↓
useInsertionEffect
   ↓
useLayoutEffect
   ↓
Browser paint
```

**Use for:** CSS-in-JS library implementation.

> For normal application development, you will rarely need this Hook.

---

# Quick Revision

| Hook                   | Remember                    |
| ---------------------- | --------------------------- |
| `useId`                | Stable unique IDs           |
| `useTransition`        | Non-urgent state update     |
| `useDeferredValue`     | Deferred value              |
| `useLayoutEffect`      | DOM work before paint       |
| `useImperativeHandle`  | Customize exposed ref       |
| `useSyncExternalStore` | External store subscription |
| `useInsertionEffect`   | CSS-in-JS style insertion   |

### Interview priority

**Must know:** `useTransition`, `useDeferredValue`, `useLayoutEffect`
**Know basics:** `useId`, `useImperativeHandle`, `useSyncExternalStore`
**Just know purpose:** `useInsertionEffect`
