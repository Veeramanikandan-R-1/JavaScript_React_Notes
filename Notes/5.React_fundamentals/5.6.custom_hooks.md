# React Fundamentals – Custom Hooks

## What are Custom Hooks?

A **Custom Hook** is a **JavaScript function that uses one or more React Hooks** and allows you to **reuse stateful logic** across multiple components.

> A custom hook **doesn't share state**. It **shares logic**. Every component calling the hook gets its own independent state.

---

# Why Custom Hooks?

Without Custom Hook

```jsx
// Component A
useEffect(() => {
  fetchUsers();
}, []);

// Component B
useEffect(() => {
  fetchUsers();
}, []);
```

Same logic is duplicated.

---

With Custom Hook

```jsx
const users = useUsers();
```

Logic is written once and reused everywhere.

---

# Example

### Custom Hook

```jsx
import { useEffect, useState } from "react";

function useUsers() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    fetch("/api/users")
      .then(res => res.json())
      .then(setUsers);
  }, []);

  return users;
}
```

### Component 1

```jsx
function Dashboard() {
  const users = useUsers();

  return <div>{users.length}</div>;
}
```

### Component 2

```jsx
function Admin() {
  const users = useUsers();

  return <ul>
    {users.map(user => (
      <li key={user.id}>{user.name}</li>
    ))}
  </ul>;
}
```

Same fetching logic is reused.

# Rules of Custom Hooks

## Rule 1: Name must start with `use`

✅ Correct

```jsx
function useUsers() {}
```

❌ Wrong

```jsx
function users() {}
```

---

## Rule 2: Call Hooks only at the top level

✅ Correct

```jsx
function useCounter() {
  const [count] = useState(0);
}
```

❌ Wrong

```jsx
if (show) {
  useState(0);
}
```

Don't call Hooks inside:

* `if`
* `for`
* `while`
* Nested functions

---

## Rule 3: Call Hooks only from

* Functional Components
* Custom Hooks

Not from regular JavaScript functions.

---

# Best Practices

### 1. Keep one responsibility

Good

```jsx
useUsers()
useAuth()
useTheme()
```

Avoid one hook doing many unrelated things.

---

### 2. Return only what's needed

```jsx
return {
  users,
  loading,
  error
};
```

Instead of exposing unnecessary internal variables.

---

### 3. Accept parameters

```jsx
function useUser(id) {
  // fetch user by id
}
```

Usage

```jsx
const user = useUser(10);
```

Makes the hook reusable.

---

### 4. Hide implementation details

Component

```jsx
const { users, loading } = useUsers();
```

The component doesn't care whether the hook uses `fetch`, `axios`, or another API internally.

---

### 5. Use multiple Hooks inside a Custom Hook

```jsx
function useAuth() {
  const [user, setUser] = useState(null);

  useEffect(() => {
    // Fetch logged-in user
  }, []);

  return user;
}
```

A custom hook can combine `useState`, `useEffect`, `useContext`, etc.

# Interview Questions

### 1. What is a Custom Hook?

A JavaScript function that starts with `use` and uses React Hooks to reuse **stateful logic** across components.

---

### 2. Can two components share state using a Custom Hook?

**No.**

Each component gets its **own independent state**.

Example:

```jsx
const count1 = useCounter();
const count2 = useCounter();
```

`count1` and `count2` are different state instances.

---

### 3. Why use Custom Hooks?

* Remove duplicate logic
* Improve readability
* Easier maintenance
* Better testing
* Better separation of concerns
