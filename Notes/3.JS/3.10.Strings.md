* Form inputs

Most React applications perform string manipulation almost every day.

---

# What is a String?

A string is a sequence of characters enclosed in quotes.

```javascript
const name = "John";
const city = 'London';
const message = `Hello`;
```

JavaScript strings are **immutable**.

> **Immutable means once a string is created, it cannot be modified. Any string operation returns a new string.**

Example

```javascript
let str = "Hello";

str.toUpperCase();

console.log(str);
```

Output

```text
Hello
```

Because `toUpperCase()` returns a new string.

Correct

```javascript
str = str.toUpperCase();
```

# String Methods Covered

* `split()`

# 1. `split()`

Splits a string into an array.

## Syntax

```javascript
string.split(separator, limit)
```

---

## Example

```javascript
const str = "React JavaScript";

const result = str.split(" ");

console.log(result);
```

Output

```javascript
["React", "JavaScript"]
```

---

## Split by Character

```javascript
const str = "ABC";

console.log(str.split(""));
```

Output

```javascript
["A","B","C"]
```

---

## Split CSV

```javascript
const csv = "John,David,Tom";

console.log(csv.split(","));
```

Output

```javascript
["John","David","Tom"]
```

---

## Using Limit

```javascript
const str = "A-B-C-D";

console.log(str.split("-", 2));
```

Output

```javascript
["A","B"]
```

---

## React Example

Search tags

```javascript
const tags = input.split(",");
```

Input

```text
react,javascript,css
```

Result

```javascript
["react","javascript","css"]
```

# 2. `substring()`

Extracts part of a string.

Returns a **new string**.

## Syntax

```javascript
string.substring(start, end)
```

* `start` → Included
* `end` → Excluded

---

## Example

```javascript
const str = "JavaScript";

console.log(str.substring(0,4));
```

Output

```text
Java
```

---

## Example

```javascript
console.log(str.substring(4));
```

Output

```text
Script
```

---

## Important Behavior

If

```javascript
substring(6,2)
```

JavaScript automatically swaps them.

Equivalent to

```javascript
substring(2,6)
```

Example

```javascript
console.log("JavaScript".substring(6,2));
```

Output

```text
vaSc
```

---

# Negative Index

```javascript
substring(-2)
```

Negative values are treated as **0**.

```javascript
"Hello".substring(-2)
```

Output

```text
Hello
```

---

# 3. `slice()`

Also extracts a portion of a string.

## Syntax

```javascript
string.slice(start, end)
```

---

## Example

```javascript
const str = "JavaScript";

console.log(str.slice(0,4));
```

Output

```text
Java
```

---

## Negative Index (Major Difference)

```javascript
console.log(str.slice(-6));
```

Output

```text
Script
```

Negative indexing starts from the end of the string.

---

## Another Example

```javascript
console.log(str.slice(-3));
```

Output

```text
ipt
```

---

# substring() vs slice()

| Feature            | substring()      | slice()     |
| ------------------ | ---------------- | ----------- |
| Negative index     | ❌ Treated as `0` | ✅ Supported |
| Swaps start/end    | ✅ Yes            | ❌ No        |
| Returns new string | ✅                | ✅           |

# 4. `includes()`

Checks whether a string contains another string.

Returns

```javascript
true
```

or

```javascript
false
```

---

## Syntax

```javascript
string.includes(searchValue)
```

---

## Example

```javascript
const str = "React JavaScript";

console.log(
str.includes("React")
);
```

Output

```text
true
```

---

## Not Found

```javascript
console.log(
str.includes("Angular")
);
```

Output

```text
false
```

---

## Starting Position

```javascript
const str = "JavaScript";

console.log(
str.includes("Script",4)
);
```

Output

```text
true
```

---

# 5. `replace()`

Replaces part of a string.

Returns a **new string**.

## Syntax

```javascript
string.replace(searchValue, replaceValue)
```

---

## Example

```javascript
const str =
"Hello World";

console.log(
str.replace("World","React")
);
```

Output

```text
Hello React
```

---

## Original Doesn't Change

```javascript
console.log(str);
```

Output

```text
Hello World
```

---

## Replace First Match Only

```javascript
const str =
"cat cat cat";

console.log(
str.replace("cat","dog")
);
```

Output

```text
dog cat cat
```

Only the first occurrence is replaced.

---

## Replace All

Modern JavaScript

```javascript
const str =
"cat cat cat";

console.log(
str.replaceAll("cat","dog")
);
```

Output

```text
dog dog dog
```

Or use a regular expression with the global (`g`) flag:

```javascript
str.replace(/cat/g, "dog");
```

---

## React Example

Cleaning API response

```javascript
const text =
apiData.replace(
"<br>",
""
);
```

# Common Mistakes

### ❌ Assuming strings are mutable

```javascript
str.replace("A","B");
```

Doesn't modify the original string.

Assign the result.

---

### ❌ Confusing `slice()` and `substring()`

Remember

`slice()`

* Supports negative index

`substring()`

* Doesn't support negative index
* Swaps indexes if start > end

---

### ❌ Forgetting `replace()` changes only the first occurrence

```javascript
"cat cat".replace("cat","dog");
```

Output

```text
dog cat
```

---

### ❌ Case-sensitive Search

```javascript
"React".includes("react");
```

Returns

```text
false
```

Normalize case when needed.

---

# Best Practices

* Use `split()` to convert strings into arrays.
* Use `slice()` when negative indexing is useful.
* Use `substring()` only when negative indexes aren't required.
* Use `includes()` for readable string existence checks.
* Remember that `replace()` replaces only the first occurrence unless using `replaceAll()` or a global regular expression.
* Always assign the result because string methods return new strings.

# Common React (6 Years Experience) Interview Questions

### 1. What is the difference between `split()` and `substring()`?

**Answer:**

* `split()` converts a string into an **array**.
* `substring()` extracts part of a string and returns a **string**.

---

### 2. What is the difference between `slice()` and `substring()`?

**Answer:**

* `slice()` supports negative indexes.
* `substring()` does not support negative indexes and swaps the indexes if `start > end`.

---

### 3. Does `replace()` modify the original string?

**Answer:**
No. Strings are immutable. `replace()` returns a new string and leaves the original unchanged.

---

### 4. How do you replace all occurrences of a string?

**Answer:**

```javascript
str.replaceAll("cat", "dog");
```

Or

```javascript
str.replace(/cat/g, "dog");
```

---

### 5. Is `includes()` case-sensitive?

**Answer:**
Yes.

```javascript
"React".includes("react");
```

Returns `false`.

For a case-insensitive search:

```javascript
str.toLowerCase().includes(search.toLowerCase());
```

---

### 6. What does `split("")` return?

**Answer:**

```javascript
"ABC".split("");
```

Returns:

```javascript
["A", "B", "C"]
```

---

### 7. Which string methods from this topic are immutable?

**Answer:**
All of them.

* `split()`
* `substring()`
* `slice()`
* `includes()`
* `replace()`

None modify the original string because JavaScript strings are immutable.

---

### 8. How are these methods commonly used in React?

| Method        | Common React Use Case                                       |
| ------------- | ----------------------------------------------------------- |
| `split()`     | Parse CSV input, tags, email usernames                      |
| `substring()` | Display previews, truncate text                             |
| `slice()`     | Extract parts of strings using positive or negative indexes |
| `includes()`  | Search, filtering, validation                               |
| `replace()`   | Clean API data, create URL slugs, format text               |

## Interview Tip (6 Years Experience)

Interviewers often combine these methods with array methods:

```javascript
const tags = input
  .split(",")
  .map(tag => tag.trim())
  .filter(tag => tag !== "");
```

This demonstrates practical string processing, array transformation, and clean coding practices commonly used in React applications.
