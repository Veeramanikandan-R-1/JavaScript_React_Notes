# JavaScript Strings — Interview Notes

Strings are **primitive and immutable** in JavaScript. String methods return a **new string**; they don't modify the original.

```js
const str = "Hello World";
```

---

## 1. `split()` ⭐⭐⭐

Converts a string into an **array** based on a separator.

```js
const str = "apple,banana,mango";

const result = str.split(",");

console.log(result);
// ["apple", "banana", "mango"]
```

### Split every character

```js
"Hello".split("");
// ["H", "e", "l", "l", "o"]
```

### Split by whitespace

```js
"Hello World JavaScript".split(" ");
// ["Hello", "World", "JavaScript"]
```

### Common React/JS use

```js
const tags = "React,JavaScript,CSS"
  .split(",")
  .map(tag => tag.trim());
```

---

# 2. `substring()` ⭐⭐

Extracts characters between two indexes.

```js
const str = "JavaScript";

console.log(str.substring(0, 4));
// "Java"
```

Syntax:

```js
str.substring(start, end);
```

`end` is **exclusive**.

### Important behavior

`substring()` treats negative values as `0`.

```js
"Hello".substring(-2, 3);
// "Hel"
```

If `start > end`, it **swaps them**:

```js
"Hello".substring(4, 1);
// "ell"
```

---

# 3. `slice()` ⭐⭐⭐

Extracts a portion of a string and returns a new string.

```js
const str = "JavaScript";

console.log(str.slice(0, 4));
// "Java"
```

Syntax:

```js
str.slice(start, end);
```

`end` is exclusive.

### Negative indexes ⭐

This is a major difference from `substring()`.

```js
const str = "JavaScript";

console.log(str.slice(-6));
// "Script"
```

```js
"Hello".slice(-3);
// "llo"
```

---

# ⭐ `substring()` vs `slice()`

| `substring()`                   | `slice()`                 |
| ------------------------------- | ------------------------- |
| Negative values treated as `0`  | Supports negative indexes |
| Swaps start/end if start > end  | Does not swap             |
| `str.substring(4, 1)` → `"ell"` | `str.slice(4, 1)` → `""`  |

### Interview recommendation

> Prefer `slice()` when you need predictable behavior and especially when working with negative indexes.

---

# 4. `includes()` ⭐⭐⭐

Checks whether a string contains a specific substring.

Returns `true` or `false`.

```js
const str = "Hello JavaScript";

console.log(str.includes("JavaScript"));
// true

console.log(str.includes("Python"));
// false
```

### Case-sensitive

```js
"Hello".includes("hello");
// false
```

Case-insensitive check:

```js
const result = "Hello".toLowerCase().includes("hello");

console.log(result); // true
```

### Optional starting position

```js
"JavaScript".includes("Script", 4);
// true
```

---

# 5. `replace()` ⭐⭐⭐

Replaces a matching part of a string and returns a **new string**.

```js
const str = "Hello World";

const result = str.replace("World", "John");

console.log(result);
// "Hello John"
```

Original remains unchanged:

```js
console.log(str);
// "Hello World"
```

### Important: Default behavior

With a plain string, `replace()` replaces only the **first occurrence**.

```js
const str = "cat cat cat";

console.log(str.replace("cat", "dog"));
// "dog cat cat"
```

### Replace all

Using regex:

```js
const str = "cat cat cat";

console.log(str.replace(/cat/g, "dog"));
// "dog dog dog"
```

Or modern `replaceAll()`:

```js
str.replaceAll("cat", "dog");
```

### Using a function ⭐

```js
const result = "hello world".replace(/\w+/g, word =>
  word.toUpperCase()
);

console.log(result);
// "HELLO WORLD"
```

# ⭐ Quick Comparison

| Method        | Purpose            | Returns    |
| ------------- | ------------------ | ---------- |
| `split()`     | String → Array     | Array      |
| `substring()` | Extract characters | String     |
| `slice()`     | Extract characters | String     |
| `includes()`  | Check existence    | Boolean    |
| `replace()`   | Replace text       | New String |

# 🎯 Important Interview Points

### Strings are immutable

```js
const str = "Hello";

str.toUpperCase();

console.log(str);
// "Hello"
```

You need:

```js
const result = str.toUpperCase();
```

### `split()` + `join()` ⭐

A common transformation:

```js
const str = "hello-world";

const result = str
  .split("-")
  .join(" ");

console.log(result);
// "hello world"
```

### `replace()` vs `replaceAll()`

```text
replace()
→ first match with string
→ regex /g can replace all

replaceAll()
→ replaces all matching occurrences
```

### 🎯 Mental Model

```text
split     → string → array
substring → extract (no negative index)
slice     → extract (supports negative index)
includes  → contains?
replace   → replace text
```

**Senior React interview takeaway:** These methods are commonly used for **search/filter logic, input normalization, formatting, parsing, and transforming API/UI data**.
