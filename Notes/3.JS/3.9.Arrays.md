# JavaScript Arrays — Interview Notes

These array methods are **very important for React**, especially for rendering, filtering data, transformations, and immutable state updates.

---

## 1. `map()` ⭐⭐⭐

Creates a **new array** by transforming every element.

```js
const numbers = [1, 2, 3];

const result = numbers.map(n => n * 2);

console.log(result); // [2, 4, 6]
```

* Returns a new array
* Does not modify the original array
* Output array normally has the same length

### React ⭐

```jsx
users.map(user => (
  <div key={user.id}>{user.name}</div>
));
```

---

# 2. `filter()` ⭐⭐⭐

Creates a new array containing elements that satisfy a condition.

```js
const numbers = [1, 2, 3, 4];

const result = numbers.filter(n => n % 2 === 0);

console.log(result); // [2, 4]
```

* Returns a new array
* Does not modify original
* Can return fewer elements or even `[]`

---

# 3. `reduce()` ⭐⭐⭐

Reduces an array to **one accumulated value**.

```js
const numbers = [1, 2, 3, 4];

const total = numbers.reduce(
  (sum, n) => sum + n,
  0
);

console.log(total); // 10
```

Syntax:

```js
array.reduce((accumulator, currentValue) => {
  return accumulator;
}, initialValue);
```

Can produce:

* Number
* String
* Object
* Array
* Any other value

### Example: grouping/counting

```js
const fruits = ["apple", "banana", "apple"];

const count = fruits.reduce((acc, fruit) => {
  acc[fruit] = (acc[fruit] || 0) + 1;
  return acc;
}, {});

console.log(count);
// { apple: 2, banana: 1 }
```

---

# 4. `find()` ⭐⭐

Returns the **first element** matching a condition.

```js
const users = [
  { id: 1, name: "John" },
  { id: 2, name: "Bob" }
];

const user = users.find(u => u.id === 2);

console.log(user);
// { id: 2, name: "Bob" }
```

If no match:

```js
undefined
```

### `find()` vs `filter()`

```text
find   → first matching element
filter → all matching elements
```

---

# 5. `some()` ⭐⭐

Checks whether **at least one** element satisfies the condition.

Returns a boolean.

```js
const numbers = [1, 3, 5, 6];

numbers.some(n => n % 2 === 0);
// true
```

Think:

> **Does at least one match?**

---

# 6. `every()` ⭐⭐

Checks whether **all** elements satisfy the condition.

Returns a boolean.

```js
const numbers = [2, 4, 6];

numbers.every(n => n % 2 === 0);
// true
```

Think:

> **Do all match?**

### `some` vs `every`

```text
some   → at least ONE → true
every  → ALL          → true
```

---

# 7. `flat()` ⭐⭐

Creates a new array by flattening nested arrays.

```js
const arr = [1, [2, 3], [4, [5]]];

console.log(arr.flat());
// [1, 2, 3, 4, [5]]
```

Default depth = `1`.

Specify depth:

```js
arr.flat(2);
// [1, 2, 3, 4, 5]
```

Flatten completely:

```js
arr.flat(Infinity);
```

---

# 8. `flatMap()` ⭐⭐

Performs:

```text
map() + flat(1)
```

in one operation.

```js
const numbers = [1, 2, 3];

const result = numbers.flatMap(n => [n, n * 2]);

console.log(result);
// [1, 2, 2, 4, 3, 6]
```

### Why use it?

Instead of:

```js
numbers.map(n => [n, n * 2]).flat();
```

use:

```js
numbers.flatMap(n => [n, n * 2]);
```

---

# 9. `sort()` ⭐⭐⭐

Sorts an array **in place** and returns the same array.

### ⚠️ Default sorting

It converts elements to strings and sorts lexicographically.

```js
const numbers = [10, 2, 5, 1];

numbers.sort();

console.log(numbers);
// [1, 10, 2, 5] ❌
```

### Numeric sorting

```js
numbers.sort((a, b) => a - b);

console.log(numbers);
// [1, 2, 5, 10]
```

Descending:

```js
numbers.sort((a, b) => b - a);
```

### ⚠️ React / immutability ⭐

Don't directly mutate state:

```js
// ❌
items.sort();
```

Create a copy:

```js
// ✅
const sorted = [...items].sort((a, b) => a - b);
```

Modern alternative:

```js
const sorted = items.toSorted((a, b) => a - b);
```

`toSorted()` returns a new sorted array without mutating the original.

---

# 10. `splice()` ⭐⭐⭐

Used to **add, remove, or replace elements**.

⚠️ **Mutates the original array.**

Syntax:

```js
array.splice(start, deleteCount, item1, item2, ...);
```

### Remove

```js
const arr = [1, 2, 3, 4];

arr.splice(1, 2);

console.log(arr);
// [1, 4]
```

Starting at index `1`, remove `2` elements.

### Add

```js
const arr = [1, 4];

arr.splice(1, 0, 2, 3);

console.log(arr);
// [1, 2, 3, 4]
```

### Replace

```js
const arr = [1, 2, 3];

arr.splice(1, 1, 20);

console.log(arr);
// [1, 20, 3]
```

---

# 11. `slice()` ⭐⭐⭐

Returns a **shallow copy** of a portion of an array.

⚠️ Does **not** modify the original.

```js
const arr = [1, 2, 3, 4, 5];

const result = arr.slice(1, 4);

console.log(result);
// [2, 3, 4]
```

End index is **exclusive**.

```text
slice(1, 4)

index:  0  1  2  3  4
value:  1  2  3  4  5
           ↑        ↑
         start     end(excluded)
```

### Copy entire array

```js
const copy = arr.slice();
```

---

# ⭐ `slice()` vs `splice()` — Very Important

| `slice()`                   | `splice()`                        |
| --------------------------- | --------------------------------- |
| Does NOT mutate             | ❌ Mutates                         |
| Returns selected portion    | Returns removed elements          |
| Used for copying/extracting | Used for add/remove/replace       |
| `slice(start, end)`         | `splice(start, deleteCount, ...)` |

Easy memory trick:

```text
SLICE  → take a piece → original unchanged
SPLICE → modify the array → original changes
```

---

# ⭐ Quick Comparison

| Method    | Returns               | Mutates? | Main Use           |
| --------- | --------------------- | -------: | ------------------ |
| `map`     | New array             |        ❌ | Transform          |
| `filter`  | New array             |        ❌ | Select             |
| `reduce`  | Any value             |       ❌* | Accumulate         |
| `find`    | Element / `undefined` |        ❌ | First match        |
| `some`    | Boolean               |        ❌ | Any match          |
| `every`   | Boolean               |        ❌ | All match          |
| `flat`    | New array             |        ❌ | Flatten            |
| `flatMap` | New array             |        ❌ | Map + flatten      |
| `sort`    | Array                 |        ✅ | Sort               |
| `splice`  | Removed elements      |        ✅ | Add/remove/replace |
| `slice`   | New array             |        ❌ | Extract/copy       |

* `reduce()` itself doesn't mutate the array, but your reducer callback **can** mutate objects or other values if you write it that way.

# 🎯 React Interview Must-Know

### ❌ Don't mutate state

```js
// ❌
items.sort();
items.splice(1, 1);
```

### ✅ Create a new array

```js
// Add
setItems(prev => [...prev, newItem]);

// Remove
setItems(prev => prev.filter(item => item.id !== id));

// Update
setItems(prev =>
  prev.map(item =>
    item.id === id
      ? { ...item, name: "Updated" }
      : item
  )
);

// Sort
setItems(prev => [...prev].sort((a, b) => a.price - b.price));
```

### ⭐ Mental Model

```text
map       → transform
filter    → select
reduce    → accumulate
find      → first match
some      → any match?
every     → all match?
flat      → flatten
flatMap   → transform + flatten
sort      → order (mutates!)
splice    → modify (mutates!)
slice     → copy/extract (doesn't mutate)
```

These are the **core array methods you should be able to explain and code from memory** in a 5-year React interview.
