# JavaScript Arrays

Arrays are one of the **most important JavaScript topics** for React developers. Every React application uses arrays for:

* Rendering UI (`map()`)
* Searching data (`find()`)
* Filtering (`filter()`)
* Calculations (`reduce()`)
* Sorting (`sort()`)
* State updates
* API responses

Most React interview coding questions involve array methods.

---

# Array Methods Overview

| Method      | Purpose                       | Returns New Array?    | Mutates Original? |
| ----------- | ----------------------------- | --------------------- | ----------------- |
| `map()`     | Transform every element       | ✅                     | ❌                 |
| `filter()`  | Keep matching elements        | ✅                     | ❌                 |
| `reduce()`  | Reduce to one value           | ❌ (returns any value) | ❌                 |
| `find()`    | First matching element        | ❌                     | ❌                 |
| `some()`    | Check if at least one matches | ❌ (Boolean)           | ❌                 |
| `every()`   | Check if all match            | ❌ (Boolean)           | ❌                 |
| `flat()`    | Flatten nested arrays         | ✅                     | ❌                 |
| `flatMap()` | Map + flatten one level       | ✅                     | ❌                 |
| `sort()`    | Sort elements                 | ❌                     | ✅                 |
| `splice()`  | Add/Remove elements           | ❌                     | ✅                 |
| `slice()`   | Extract part of array         | ✅                     | ❌                 |

# 1. `map()`

Creates a **new array** by transforming every element.

## Syntax

```javascript
array.map((item, index, array) => {})
```

---

## Example

```javascript
const nums = [1,2,3];

const doubled = nums.map(num => num * 2);

console.log(doubled);
```

Output

```text
[2,4,6]
```

Original array remains unchanged.

---

## React Example

```jsx
const users = [
  { id: 1, name: "John" },
  { id: 2, name: "David" }
];

return (
  <>
    {users.map(user => (
      <p key={user.id}>{user.name}</p>
    ))}
  </>
);
```

This is the **most common React array operation**.

---

# 2. `filter()`

Returns a **new array** containing only elements that satisfy the condition.

```javascript
const nums = [1,2,3,4,5];

const even = nums.filter(num => num % 2 === 0);

console.log(even);
```

Output

```text
[2,4]
```

---

## React Example

Search functionality

```javascript
const activeUsers =
users.filter(user => user.active);
```

---

---

```javascript
filter()
```

Removes unwanted elements.


# 3. `reduce()`

Reduces an array into **a single value**.

Can return:

* Number
* String
* Object
* Array
* Map

## Syntax

```javascript
array.reduce((accumulator, current) => {}, initialValue)
```

---

## Sum Example

```javascript
const nums = [1,2,3];

const total =
nums.reduce((sum, num) => sum + num, 0);

console.log(total);
```

Output

```text
6
```

---

## Count Occurrences

```javascript
const fruits =
["apple","apple","banana"];

const result =
fruits.reduce((acc, fruit) => {
    acc[fruit] = (acc[fruit] || 0) + 1;
    return acc;
}, {});

console.log(result);
```

Output

```javascript
{
  apple:2,
  banana:1
}
```

---

## React Example

Calculate total price.

```javascript
const total =
cart.reduce(
    (sum,item)=>sum+item.price,
    0
);
```

# 7. `flat()`

Flattens nested arrays.

```javascript
const arr =
[1,[2,3],[4]];

console.log(arr.flat());
```

Output

```text
[1,2,3,4]
```

---

## Flatten Multiple Levels

```javascript
const arr =
[1,[2,[3]]];

console.log(arr.flat(2));
```

Output

```text
[1,2,3]
```

---

# 8. `flatMap()`

Performs

```text
map()

+

flat(1)
```

in one operation.

---

Example

```javascript
const words =
["hello world","good day"];

const result =
words.flatMap(
word => word.split(" ")
);

console.log(result);
```

Output

```text
["hello","world","good","day"]
```

Equivalent to

```javascript
words.map(word=>word.split(" "))
     .flat();
```

# 9. `sort()`

Sorts the original array.

⚠️ It **mutates** the array.

---

## Strings

```javascript
const fruits =
["Banana","Apple","Orange"];

fruits.sort();
```

Output

```text
["Apple","Banana","Orange"]
```

---

## Numbers (Important Interview Question)

Wrong

```javascript
const nums=[10,5,100];

nums.sort();
```

Output

```text
[10,100,5]
```

Because sorting is **lexicographical** by default.

---

Correct

```javascript
nums.sort((a,b)=>a-b);
```

Ascending

```text
[5,10,100]
```

Descending

```javascript
nums.sort((a,b)=>b-a);
```

---

## React Best Practice

Avoid mutating state.

❌

```javascript
users.sort();
```

✅

```javascript
const sorted =
[...users].sort(
(a,b)=>a.age-b.age
);
```

---

# 10. `splice()`

Changes the original array.

Can

* Remove
* Insert
* Replace

---

## Remove

```javascript
const nums=[1,2,3,4];

nums.splice(1,2);

console.log(nums);
```

Output

```text
[1,4]
```

---

## Insert

```javascript
const nums=[1,4];

nums.splice(1,0,2,3);

console.log(nums);
```

Output

```text
[1,2,3,4]
```

---

## Replace

```javascript
const nums=[1,2,3];

nums.splice(1,1,20);
```

Output

```text
[1,20,3]
```

---

# 11. `slice()`

Returns a portion of an array.

Does **not mutate** the original.

```javascript
const nums=[1,2,3,4];

const part=
nums.slice(1,3);

console.log(part);
```

Output

```text
[2,3]
```

Original

```text
[1,2,3,4]
```

---

# slice() vs splice()

| slice()                     | splice()                       |
| --------------------------- | ------------------------------ |
| Doesn't modify original     | Modifies original              |
| Returns extracted array     | Returns removed elements       |
| Used for copying/extracting | Used for insert/delete/replace |

# Common Mistakes

### ❌ Using `map()` to filter data

```javascript
users.map(...)
```

Use `filter()` when removing elements.

---

### ❌ Forgetting `find()` returns an object

```javascript
find()
```

does **not** return an array.

---

### ❌ Using `sort()` directly on React state

```javascript
users.sort();
```

Mutates state.

Always copy first.

---

### ❌ Confusing `slice()` and `splice()`

Remember

```text
slice

↓

Safe
```

```text
splice

↓

Mutates
```

---

### ❌ Forgetting Initial Value in `reduce()`

```javascript
nums.reduce((a,b)=>a+b);
```

Works for non-empty arrays but can throw an error on an empty array.

Prefer

```javascript
nums.reduce((a,b)=>a+b,0);
```

---

# Best Practices

* Use `map()` for rendering JSX.
* Use `filter()` for search and conditional lists.
* Use `find()` when only one item is required.
* Always provide an initial value to `reduce()`.
* Never call `sort()` directly on React state—copy first.
* Prefer `slice()` for non-mutating extraction.
* Avoid `splice()` on React state because it mutates the array.

# Common React (6 Years Experience) Interview Questions

### 1. What is the difference between `map()` and `forEach()`?

**Answer:**

* `map()` returns a **new array** and is used for transforming data.
* `forEach()` returns `undefined` and is used for side effects (e.g., logging, API calls). In React, `map()` is used to render lists.

---

### 2. What is the difference between `map()` and `filter()`?

**Answer:**

* `map()` transforms every element and keeps the array length the same.
* `filter()` removes elements that don't match the condition, so the resulting array may be smaller.

---

### 3. What is the difference between `find()` and `filter()`?

**Answer:**

* `find()` returns the **first matching element** (or `undefined`).
* `filter()` returns **all matching elements** in a new array.

---

### 4. What is the difference between `some()` and `every()`?

**Answer:**

* `some()` returns `true` if **at least one** element satisfies the condition.
* `every()` returns `true` only if **all** elements satisfy the condition.

---

### 5. What is `reduce()` used for?

**Answer:**
It reduces an array to a single value such as a sum, average, object, grouped data, or flattened result.

---

### 6. Why can `sort()` produce incorrect results for numbers?

**Answer:**
By default, `sort()` compares elements as **strings** (lexicographical order). Use a comparator:

```javascript
arr.sort((a, b) => a - b); // Ascending
```

---

### 7. Why shouldn't you use `sort()` or `splice()` directly on React state?

**Answer:**
Both methods mutate the original array. React expects immutable updates. Always create a copy first:

```javascript
const sorted = [...users].sort((a, b) => a.age - b.age);
```

---

### 8. What is the difference between `slice()` and `splice()`?

| `slice()`                   | `splice()`                                          |
| --------------------------- | --------------------------------------------------- |
| Returns a new array         | Modifies the original array                         |
| Used for copying/extracting | Used for inserting, deleting, or replacing elements |

---

### 9. What is the difference between `flat()` and `flatMap()`?

**Answer:**

* `flat()` only flattens nested arrays.
* `flatMap()` first maps each element, then flattens the result by **one level**. It is equivalent to:

```javascript
arr.map(...).flat();
```

---

### 10. Which array methods mutate the original array?

**Answer:**
From this topic:

* ✅ Mutates: `sort()`, `splice()`
* ❌ Does **not** mutate: `map()`, `filter()`, `reduce()`, `find()`, `some()`, `every()`, `flat()`, `flatMap()`, `slice()`

> **Interview Tip:** React developers should prefer non-mutating methods (`map`, `filter`, `slice`, `reduce`) for state updates and avoid mutating methods (`sort`, `splice`) unless operating on a copied array.
