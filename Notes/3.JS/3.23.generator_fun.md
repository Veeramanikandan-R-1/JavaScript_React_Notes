### Generator Function — in short

A **generator function** is a JavaScript function that can **pause its execution** and **resume later**.

It is declared using `function*` and uses the `yield` keyword.

```javascript
function* numbers() {
  yield 1;
  yield 2;
  yield 3;
}

const gen = numbers();

console.log(gen.next()); // { value: 1, done: false }
console.log(gen.next()); // { value: 2, done: false }
console.log(gen.next()); // { value: 3, done: false }
console.log(gen.next()); // { value: undefined, done: true }
```

### Key points

* `function*` → defines a generator.
* `yield` → pauses the function and returns a value.
* `.next()` → resumes execution until the next `yield`.
* `done: true` → generator has finished.
* Useful for **iterators, lazy data processing, and controlling execution flow**.

**Easy way to remember:**

> Normal function → runs from start to finish.
> Generator → **runs → pauses → resumes → pauses → finishes**.

---

We need generator functions mainly when we want to **control how a function executes step-by-step** instead of running everything at once.

### Simple example

Imagine you have **1 million records**.

Without a generator:

```js
function getNumbers() {
  return [1, 2, 3, 4, 5]; // all values created at once
}
```

With a generator:

```js
function* getNumbers() {
  yield 1;
  yield 2;
  yield 3;
  yield 4;
  yield 5;
}
```

Now values are produced **one at a time**:

```js
const numbers = getNumbers();

console.log(numbers.next().value); // 1
console.log(numbers.next().value); // 2
```

### Why useful?

1. **Memory efficient** — doesn't create all values at once.
2. **Lazy execution** — produces a value only when needed.
3. **Pause/resume execution** — useful when controlling complex workflows.
4. **Custom iterators** — can easily create objects that work with `for...of`.
5. **Redux-Saga** — an important real-world use case in React/Redux. Sagas use generators to control asynchronous workflows:

```js
function* fetchUser() {
  const user = yield call(api.getUser);
  yield put({ type: "USER_SUCCESS", user });
}
```

### Interview one-liner

> **Generators allow a function to pause and resume execution, producing values lazily using `yield`.**

For normal React development, you won't use generators very often **unless you're working with Redux-Saga or advanced iteration/async-flow patterns**.
