# JavaScript Data Types — Interview Notes

JavaScript data types are broadly divided into **Primitive** and **Reference/Object** types.

---

# 1. Primitive Types ⭐

Primitive values are **immutable** and are not objects.

JavaScript has **7 primitive types**:

```text id="q2qv3x"
1. string
2. number
3. bigint
4. boolean
5. undefined
6. null
7. symbol
```

### Examples

```js id="v6s2na"
const name = "John";        // string
const age = 30;             // number
const isActive = true;      // boolean
const value = undefined;    // undefined
const data = null;          // null
const big = 123n;           // bigint
const id = Symbol("id");    // symbol
```

### Important: Primitive values are immutable

```js id="qk8e6f"
let name = "John";

name[0] = "B";

console.log(name); // "John"
```

You don't modify the existing string; operations create new values.

---

# 2. Reference Types

In JavaScript, **objects are non-primitive values**.

Common examples:

```text id="e2v14n"
Object
Array
Function
Date
Map
Set
RegExp
...
```

```js id="4hz7op"
const user = {
  name: "John",
  age: 30
};

const numbers = [1, 2, 3];

function greet() {
  console.log("Hello");
}
```

### Reference behavior ⭐

Variables holding objects contain a **reference to the object**.

```js id="4t8xmw"
const user1 = { name: "John" };
const user2 = user1;

user2.name = "Bob";

console.log(user1.name); // "Bob"
```

Both variables refer to the same object.

### Comparison

```js id="9ej9ih"
const a = { x: 1 };
const b = { x: 1 };

console.log(a === b); // false
```

Although their contents are identical, they are **different object references**.

```js id="n5nj9t"
const a = { x: 1 };
const b = a;

console.log(a === b); // true
```

# 3. `typeof` ⭐

`typeof` returns a **string describing the type of a value**.

```js id="w2x3b5"
typeof "hello"     // "string"
typeof 10          // "number"
typeof true        // "boolean"
typeof undefined   // "undefined"
typeof 10n         // "bigint"
typeof Symbol()    // "symbol"
typeof {}          // "object"
typeof []          // "object"
typeof function(){} // "function"
```

### ⚠️ Famous interview question

```js id="wdj1t7"
typeof null;
```

Result:

```text id="l3gk0w"
"object"
```

This is a **historical JavaScript behavior/legacy quirk**.

So:

```js id="as7j54"
typeof null === "object"; // true
```

If you need to specifically check `null`:

```js id="m8jv19"
value === null
```

### Arrays

```js id="s7y2h8"
typeof [] === "object"; // true
```

Use:

```js id="r7g5xk"
Array.isArray(value);
```

---

# 4. `instanceof` ⭐

`instanceof` checks whether an object's **prototype chain contains the `prototype` property of a constructor**.

```js id="e6p2fy"
const user = {};

console.log(user instanceof Object); // true
```

### Arrays

```js id="1oh0xm"
const numbers = [1, 2, 3];

console.log(numbers instanceof Array);  // true
console.log(numbers instanceof Object); // true
```

Why both?

```text id="6a7v7m"
Array
 ↓
Object
```

An array's prototype chain ultimately includes `Object.prototype`.

### Classes

```js id="t5t2j0"
class Person {}

const person = new Person();

console.log(person instanceof Person); // true
```

### `instanceof` with primitives

```js id="x7w4l2"
"hello" instanceof String; // false
```

Because `"hello"` is a primitive, not a `String` object.

But:

```js id="o4fl5v"
new String("hello") instanceof String; // true
```

---

# ⭐ `typeof` vs `instanceof`

| `typeof`                      | `instanceof`                       |
| ----------------------------- | ---------------------------------- |
| Returns a type string         | Returns `true`/`false`             |
| Good for primitive types      | Mainly useful for objects          |
| `typeof 10` → `"number"`      | `10 instanceof Number` → `false`   |
| `typeof []` → `"object"`      | `[] instanceof Array` → `true`     |
| `typeof null` → `"object"` ⚠️ | `null instanceof Object` → `false` |

### Practical type checking

```js id="8p9c6d"
function check(value) {
  if (typeof value === "string") {
    console.log("String");
  }

  if (Array.isArray(value)) {
    console.log("Array");
  }

  if (value instanceof Date) {
    console.log("Date");
  }
}
```

### Must Remember

> **Primitive values are immutable; objects are mutable and are compared by reference.**

> **`typeof` is useful for basic type checking, but has quirks such as `typeof null === "object"` and `typeof [] === "object"`.**

> **`instanceof` checks the prototype chain and is mainly useful for determining whether an object is an instance of a particular constructor/class.**

> For arrays, prefer **`Array.isArray(value)`** rather than `typeof value === "array"`—because `"array"` is not a valid `typeof` result.
