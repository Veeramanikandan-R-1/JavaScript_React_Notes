# JavaScript Date — Interview Notes

## 1. `Date` API ⭐⭐⭐

JavaScript's `Date` object is used to represent a **specific point in time**.

### Current date/time

```js
const now = new Date();

console.log(now);
```

### Common methods

```js
const date = new Date();

date.getFullYear(); // 2026
date.getMonth();    // 0-11 ⚠️ January = 0
date.getDate();     // Day of month: 1-31
date.getDay();      // Day of week: 0-6 (Sunday = 0)

date.getHours();
date.getMinutes();
date.getSeconds();
```

### Important ⭐

```js
date.getMonth()
```

is **0-based**:

```text
January → 0
February → 1
...
December → 11
```

---

### Creating a specific date

```js
const date = new Date("2026-08-27");

console.log(date);
```

You can also use components:

```js
const date = new Date(2026, 7, 27);

console.log(date);
```

⚠️ Month is zero-based, so `7` = August.

---

### Timestamp

A JavaScript `Date` internally represents time as **milliseconds since Unix epoch**:

```js
const now = Date.now();

console.log(now);
// e.g. 17878...
```

Convert timestamp to Date:

```js
const date = new Date(Date.now());
```

### Comparing dates

```js
const d1 = new Date("2026-08-27");
const d2 = new Date("2026-08-28");

console.log(d2 > d1); // true
```

### Difference between dates

```js
const start = new Date("2026-08-27");
const end = new Date("2026-08-28");

const diffMs = end - start;

const diffDays = diffMs / (1000 * 60 * 60 * 24);

console.log(diffDays); // 1
```

# 2. `Intl.DateTimeFormat` ⭐⭐⭐

Used to **format dates according to a locale and options**.

It is generally preferable to manually constructing date strings when you need locale-aware formatting.

```js
const date = new Date("2026-08-27");

const formatter = new Intl.DateTimeFormat("en-IN");

console.log(formatter.format(date));
// 27/8/2026 (format can vary by environment)
```

### With options

```js
const formatter = new Intl.DateTimeFormat("en-IN", {
  day: "2-digit",
  month: "long",
  year: "numeric"
});

console.log(formatter.format(new Date()));
// 27 August 2026
```

### Different locales ⭐

```js
new Intl.DateTimeFormat("en-US").format(new Date());
// 8/27/2026

new Intl.DateTimeFormat("en-IN").format(new Date());
// 27/8/2026
```

### Date + time

```js
const formatter = new Intl.DateTimeFormat("en-IN", {
  dateStyle: "medium",
  timeStyle: "short"
});

console.log(formatter.format(new Date()));
```

### React usage

Useful when displaying dates based on the user's locale:

```jsx
const formattedDate = new Intl.DateTimeFormat("en-IN", {
  day: "2-digit",
  month: "short",
  year: "numeric"
}).format(new Date());

return <span>{formattedDate}</span>;
```

# 3. `Date` vs `new Date()` ⭐⭐⭐

This is an important interview question.

### `Date`

`Date` **without `new`** is a function that returns the **current date/time as a string**.

```js
console.log(Date());
```

Example output:

```text
"Thu Aug 27 2026 09:30:00 GMT+0530 ..."
```

```js
typeof Date();
// "string"
```

---

### `new Date()`

`new Date()` creates a **Date object** representing the current date/time.

```js
const date = new Date();

console.log(date);
```

```js
typeof date;
// "object"
```

### Main difference ⭐

```js
Date();
// → String

new Date();
// → Date object
```

You can call Date as a function, but you **must use `new` to create a Date object**.
