# JavaScript ES6+ — Interview Notes

**ES6 (ECMAScript 2015)** was a major JavaScript release that introduced `let`, `const`, arrow functions, classes, modules, destructuring, spread/rest, promises, etc.

---

## 1. `let` ⭐⭐⭐

Block-scoped variable. Can be reassigned.

```js
let count = 10;
count = 20; // ✅
```

```js
if (true) {
  let x = 10;
}

console.log(x); // ❌ ReferenceError
```

### Important

* Block scoped
* Can be reassigned
* Cannot be redeclared in the same scope
* Has **Temporal Dead Zone (TDZ)**

---

# 2. `const` ⭐⭐⭐

Block-scoped variable that **cannot be reassigned**.

```js
const name = "John";

// name = "Bob"; // ❌
```

### ⚠️ Object/Array can still be mutated

```js
const user = {
  name: "John"
};

user.name = "Bob"; // ✅
```

`const` prevents **reassignment of the reference**, not object mutation.

---

# 3. Template Literals ⭐⭐⭐

Use backticks `` ` `` for strings and `${}` for interpolation.

```js
const name = "John";
const age = 30;

const message = `My name is ${name} and I am ${age}`;
```

### Multi-line strings

```js
const text = `
  Hello
  World
`;
```

### Expression support

```js
const a = 10;
const b = 20;

console.log(`Total: ${a + b}`);
// Total: 30
```

---

# 4. Destructuring ⭐⭐⭐

Extract values from arrays/objects into variables.

### Object

```js
const user = {
  name: "John",
  age: 30
};

const { name, age } = user;
```

### Array

```js
const numbers = [10, 20, 30];

const [first, second] = numbers;

console.log(first);  // 10
console.log(second); // 20
```

### Rename

```js
const { name: userName } = user;
```

### Default

```js
const { city = "Chennai" } = user;
```

Very common in React:

```jsx
function User({ name, age }) {
  return <div>{name} - {age}</div>;
}
```

---

# 5. Spread Operator `...` ⭐⭐⭐

Expands an iterable/object.

### Array

```js
const a = [1, 2];
const b = [3, 4];

const result = [...a, ...b];
// [1, 2, 3, 4]
```

### Object

```js
const user = {
  name: "John",
  age: 30
};

const updated = {
  ...user,
  age: 31
};
```

### React ⭐

```js
setUser(prev => ({
  ...prev,
  name: "Bob"
}));
```

⚠️ Spread performs a **shallow copy**.

---

# 6. Rest Operator `...` ⭐⭐⭐

Collects multiple values into an array/object.

### Function parameters

```js
function sum(...numbers) {
  return numbers.reduce((sum, n) => sum + n, 0);
}

sum(1, 2, 3); // 6
```

### Object destructuring

```js
const user = {
  name: "John",
  age: 30,
  city: "Chennai"
};

const { name, ...details } = user;

console.log(details);
// { age: 30, city: "Chennai" }
```

### Easy difference

```text
Spread → expands
Rest   → collects
```

---

# 7. Modules ⭐⭐⭐

ES6 introduced native JavaScript modules using:

```text
export
import
```

### Named export

```js
// math.js
export const add = (a, b) => a + b;
```

```js
// app.js
import { add } from "./math.js";
```

### Default export

```js
// User.js
export default function User() {}
```

```js
import User from "./User.js";
```

### Multiple exports

```js
export const add = () => {};
export const subtract = () => {};
```

```js
import { add, subtract } from "./math.js";
```

### Why modules?

* Encapsulation
* Reusability
* Avoid global variables
* Dependency management
* Better code organization

React heavily relies on ES modules.

---

# 8. Classes ⭐⭐

ES6 introduced `class` syntax for creating objects using constructor/prototype-based behavior.

```js
class User {
  constructor(name) {
    this.name = name;
  }

  greet() {
    console.log(`Hello ${this.name}`);
  }
}

const user = new User("John");

user.greet();
```

### Inheritance

```js
class Admin extends User {
  deleteUser() {
    console.log("User deleted");
  }
}
```

### Important

Classes are essentially a **more convenient syntax over JavaScript's prototype-based inheritance**.

# ⭐ Other Important ES6+ Features

These are worth knowing for a React interview.

## 9. Arrow Functions ⭐⭐⭐

```js
const add = (a, b) => a + b;
```

Important difference:

> Arrow functions don't have their own `this`; they inherit it lexically.

---

## 10. Default Parameters ⭐⭐

```js
function greet(name = "Guest") {
  console.log(name);
}

greet(); // Guest
```

---

## 11. Enhanced Object Literals ⭐⭐

### Property shorthand

```js
const name = "John";
const age = 30;

const user = {
  name,
  age
};
```

Instead of:

```js
const user = {
  name: name,
  age: age
};
```

### Method shorthand

```js
const user = {
  greet() {
    console.log("Hello");
  }
};
```

---

# 12. Promises ⭐⭐⭐

ES6 introduced native `Promise`.

Used for asynchronous operations.

```js
fetch("/api/users")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));
```

Modern React code commonly uses:

```js
async function getUsers() {
  const response = await fetch("/api/users");
  return response.json();
}
```

---

# 13. `Map` and `Set` ⭐⭐

### `Set`

Stores **unique values**.

```js
const numbers = new Set([1, 2, 2, 3]);

console.log(numbers);
// Set(3) {1, 2, 3}
```

Useful for removing duplicates:

```js
const unique = [...new Set([1, 2, 2, 3])];

console.log(unique);
// [1, 2, 3]
```

### `Map`

Stores key-value pairs.

```js
const map = new Map();

map.set("name", "John");
map.set("age", 30);

console.log(map.get("name"));
// John
```

Unlike objects, `Map` can use **objects/functions as keys**.

---

# 14. `Symbol` ⭐

Creates a unique primitive value.

```js
const id = Symbol("id");

console.log(id);
```

Two symbols are always different:

```js
Symbol("id") === Symbol("id");
// false
```

Mainly useful for unique object property keys and certain language-level protocols.

---

# 15. Iterators & `for...of` ⭐⭐

ES6 introduced the iterator protocol and `for...of`.

```js
const numbers = [10, 20, 30];

for (const number of numbers) {
  console.log(number);
}
```

`for...of` iterates over **values**.

Compare:

```js
for (const index in numbers) {
  console.log(index); // indexes
}

for (const value of numbers) {
  console.log(value); // values
}
```

---

# 16. `Array.from()` ⭐⭐

Creates an array from an iterable or array-like value.

```js
const str = "hello";

const chars = Array.from(str);

console.log(chars);
// ["h", "e", "l", "l", "o"]
```

---

# 17. `Object.assign()` ⭐⭐

Copies properties between objects.

```js
const user = { name: "John" };

const updated = Object.assign({}, user, {
  age: 30
});
```

Today, spread is often preferred:

```js
const updated = {
  ...user,
  age: 30
};
```

---

# 18. Optional Chaining `?.` ⭐⭐⭐

**ES2020**, not ES6, but extremely important modern JavaScript.

```js
const city = user?.address?.city;
```

Prevents errors when an intermediate value is `null`/`undefined`.

---

# 19. Nullish Coalescing `??` ⭐⭐⭐

**ES2020**.

Provides a fallback only for `null` or `undefined`.

```js
const name = user.name ?? "Guest";
```

Difference:

```js
0 || 10;  // 10
0 ?? 10;  // 0
```

---

# 20. `async/await` ⭐⭐⭐

**ES2017**.

Makes Promise-based asynchronous code easier to read.

```js
async function getUser() {
  try {
    const response = await fetch("/api/user");
    const user = await response.json();

    return user;
  } catch (error) {
    console.error(error);
  }
}
```
