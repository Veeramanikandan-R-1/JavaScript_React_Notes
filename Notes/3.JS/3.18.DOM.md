# JavaScript DOM — Interview Notes

**DOM (Document Object Model)** is a programming representation of an HTML document. JavaScript can use it to **read, modify, add, and remove HTML elements**.

> In React, you normally don't manipulate the DOM directly; React manages the DOM through its rendering/reconciliation process. But DOM knowledge is still important for browser APIs, refs, event handling, and interviews.

---

# 1. DOM Tree ⭐⭐⭐

Browser converts HTML into a **tree of nodes**.

```html
<div>
  <h1>Hello</h1>
  <p>Welcome</p>
</div>
```

Conceptually:

```text
Document
   │
   └── div
       ├── h1
       │   └── "Hello"
       │
       └── p
           └── "Welcome"
```

Each HTML element becomes an **Element node**, while text becomes a **Text node**.

JavaScript accesses this tree through:

```js
document
```

---

# 2. `querySelector()` ⭐⭐⭐

Returns the **first element** matching a CSS selector.

```js
const element = document.querySelector(".title");
```

Examples:

```js
document.querySelector("#app");
document.querySelector(".btn");
document.querySelector("div");
document.querySelector(".parent .child");
```

### Multiple elements

Use `querySelectorAll()`:

```js
const buttons = document.querySelectorAll(".btn");
```

It returns a **NodeList**.

### Important

```text
querySelector()
→ first matching element

querySelectorAll()
→ all matching elements
```

---

# 3. `createElement()` ⭐⭐⭐

Creates a new DOM element.

```js
const div = document.createElement("div");

div.textContent = "Hello";
```

⚠️ Creating an element does **not** automatically add it to the page.

You need to append it.

---

# 4. `appendChild()` ⭐⭐⭐

Adds a node as the **last child** of a parent.

```js
const div = document.createElement("div");

div.textContent = "Hello";

document.body.appendChild(div);
```

DOM:

```text
body
 ├── existing element
 └── div  ← appended
```

### Important

If the node already exists somewhere else, `appendChild()` **moves it**, rather than cloning it.

---

# 5. `removeChild()` ⭐⭐

Removes a child from its parent.

```js
const parent = document.querySelector(".parent");
const child = document.querySelector(".child");

parent.removeChild(child);
```

Modern alternative:

```js
child.remove();
```

---

# 6. `closest()` ⭐⭐⭐

Finds the **nearest ancestor** (including the element itself) matching a CSS selector.

HTML:

```html
<div class="card">
  <button class="delete">Delete</button>
</div>
```

JavaScript:

```js
const button = document.querySelector(".delete");

const card = button.closest(".card");

console.log(card);
```

Result:

```text
button
  ↑
card ← closest matching ancestor
```

### Very useful for event delegation ⭐

```js
document.addEventListener("click", (event) => {
  const button = event.target.closest(".delete");

  if (button) {
    console.log("Delete clicked");
  }
});
```

---

# 7. `classList` ⭐⭐⭐

Provides methods to manipulate an element's CSS classes.

```js
const button = document.querySelector("button");
```

### `add()`

```js
button.classList.add("active");
```

### `remove()`

```js
button.classList.remove("active");
```

### `toggle()`

Adds the class if absent, removes it if present.

```js
button.classList.toggle("active");
```

### `contains()`

Checks whether the class exists.

```js
button.classList.contains("active");
// true / false
```

### `replace()`

```js
button.classList.replace("old", "new");
```

### Multiple classes

```js
button.classList.add("active", "large");
```

---

# ⭐ Practical Example

Create a button dynamically:

```js
const button = document.createElement("button");

button.textContent = "Click Me";
button.classList.add("btn", "primary");

document.body.appendChild(button);

button.addEventListener("click", () => {
  button.classList.toggle("active");
});
```

# ⭐ Common DOM Operations

```js
// Find
const el = document.querySelector(".box");

// Create
const div = document.createElement("div");

// Modify
div.textContent = "Hello";

// Add
document.body.appendChild(div);

// Remove
div.remove();

// Find nearest parent
el.closest(".container");

// Classes
el.classList.add("active");
el.classList.remove("active");
el.classList.toggle("active");
```

# 🎯 React Connection ⭐⭐⭐

In React, **avoid doing this directly**:

```js
document.querySelector(".button").classList.add("active");
```

Prefer React state:

```jsx
const [active, setActive] = useState(false);

<button
  className={active ? "button active" : "button"}
  onClick={() => setActive(prev => !prev)}
>
  Click
</button>
```

For direct DOM access when genuinely needed, use `useRef`:

```jsx
const inputRef = useRef(null);

<input ref={inputRef} />

inputRef.current.focus();
```

### Why?

React follows a **declarative approach**:

```text
State → React render → DOM
```

Rather than:

```text
Manually manipulate DOM → UI
```

### ⭐ Interview One-Liner

> **The DOM is a tree representation of the HTML document, and APIs such as `querySelector`, `createElement`, `appendChild`, and `classList` allow JavaScript to interact with and modify that tree; in React, direct DOM manipulation should generally be avoided in favor of state, props, and refs.**
