# 1. What is DOM?

DOM (Document Object Model) is a **tree-like representation** of an HTML document created by the browser.

It converts HTML into JavaScript objects so that JavaScript can read and modify the page dynamically.

**HTML**

```html
<html>
  <body>
    <h1>Hello</h1>
    <button>Click</button>
  </body>
</html>
```

**DOM**

```
Document
│
└── html
     │
     ├── head
     │
     └── body
          │
          ├── h1
          │    └── "Hello"
          │
          └── button
               └── "Click"
```

Each item is called a **Node**.

---

## Why DOM exists?

Without DOM:

* JavaScript cannot access HTML.
* Cannot update UI dynamically.
* Cannot respond to user interactions.

Example:

```js
document.querySelector("h1").textContent = "Welcome";
```

The browser updates the UI immediately.

# 2. DOM Tree

The browser converts HTML into a hierarchical tree.

Example

```html
<div id="app">
    <h1>React</h1>
    <p>Hello</p>
</div>
```

DOM Tree

```
Document
│
└── html
     │
     └── body
           │
           └── div
               │
               ├── h1
               │
               └── p
```

---

## Types of Nodes

| Node     | Example          |
| -------- | ---------------- |
| Document | document         |
| Element  | div, p           |
| Text     | Hello            |
| Comment  | <!-- comment --> |

---

## Parent and Child

```html
<div>
    <span>Hello</span>
</div>
```

```
div
└── span
```

```
div → parent

span → child
```

---

## Siblings

```html
<div>
    <h1></h1>
    <p></p>
</div>
```

```
h1 and p are siblings.
```

---

## Common DOM Navigation

```js
element.parentElement

element.children

element.firstElementChild

element.lastElementChild

element.nextElementSibling

element.previousElementSibling
```

# 3. querySelector()

Returns the **first matching element**.

Syntax

```js
document.querySelector(selector)
```

Example

```html
<p class="title">Hello</p>
```

```js
const title = document.querySelector(".title");

console.log(title.textContent);
```

Output

```
Hello
```

---

## Selecting by id

```js
document.querySelector("#box");
```

---

## Selecting class

```js
document.querySelector(".card");
```

---

## Selecting tag

```js
document.querySelector("button");
```

---

## Complex selectors

```js
document.querySelector(".card h2");

document.querySelector("ul li");

document.querySelector("input[type='text']");
```

---

## querySelectorAll()

Returns **all matching elements**.

```js
const buttons = document.querySelectorAll("button");

buttons.forEach(btn => {
    console.log(btn);
});
```

Returns a **NodeList**, not an Array (although it supports `forEach`).

---

## Difference

| querySelector     | querySelectorAll |
| ----------------- | ---------------- |
| First match       | All matches      |
| Returns Element   | Returns NodeList |
| Null if not found | Empty NodeList   |

---

# 4. createElement()

Creates a new DOM element **in memory**.

Syntax

```js
document.createElement(tagName)
```

Example

```js
const div = document.createElement("div");
```

Nothing appears on the page yet because it hasn't been added to the DOM.

---

## Add content

```js
const p = document.createElement("p");

p.textContent = "Hello";
```

---

## Add class

```js
p.className = "message";
```

or

```js
p.classList.add("message");
```

---

## Add attributes

```js
const img = document.createElement("img");

img.src = "logo.png";

img.alt = "Logo";
```

---

# 5. appendChild()

Adds a child element to another element.

Syntax

```js
parent.appendChild(child)
```

Example

```js
const ul = document.querySelector("ul");

const li = document.createElement("li");

li.textContent = "React";

ul.appendChild(li);
```

Result

```html
<ul>
   <li>React</li>
</ul>
```

---

## Important

`appendChild()` **moves** an existing element instead of copying it.

```js
parent2.appendChild(child);
```

The child is removed from its old parent and added to the new one.

---

## append() vs appendChild()

| append()       | appendChild() |
| -------------- | ------------- |
| Multiple items | One node      |
| Accepts text   | Only Node     |
| Modern         | Older         |

Example

```js
div.append("Hello");

div.append(span);
```

---

# 6. removeChild()

Removes a child node from its parent.

Syntax

```js
parent.removeChild(child)
```

Example

```html
<ul>
   <li>React</li>
</ul>
```

```js
const ul = document.querySelector("ul");

const li = document.querySelector("li");

ul.removeChild(li);
```

---

## Modern alternative

```js
li.remove();
```

Preferred because it's simpler and doesn't require the parent.

---

# 7. closest()

Finds the **nearest ancestor (including itself)** that matches a selector.

Syntax

```js
element.closest(selector)
```

Example

```html
<div class="card">

    <button>Delete</button>

</div>
```

```js
const button = document.querySelector("button");

const card = button.closest(".card");
```

Returns

```
<div class="card">
```

---

## Useful for Event Delegation

Instead of checking many parents manually:

```js
if(e.target.closest(".menu"))
```

Very common in production code.

---

# 8. classList

Used to manipulate CSS classes.

---

## add()

```js
element.classList.add("active");
```

---

## remove()

```js
element.classList.remove("active");
```

---

## toggle()

```js
element.classList.toggle("dark");
```

If exists → removes.

If doesn't exist → adds.

---

## contains()

```js
if(element.classList.contains("active"))
```

Returns true/false.

---

## replace()

```js
element.classList.replace("old","new");
```

---

## Multiple classes

```js
element.classList.add(
    "btn",
    "primary"
);
```

---

## Why classList instead of className?

Bad

```js
element.className = "btn";
```

Removes all existing classes.

Better

```js
element.classList.add("btn");
```

Keeps existing classes.

# DOM vs React

Interviewers often ask this.

Traditional JavaScript

```js
const div = document.createElement("div");

document.body.appendChild(div);
```

React

```jsx
return <div>Hello</div>;
```

React creates a **Virtual DOM**, compares changes (diffing), and updates only the necessary real DOM nodes, avoiding manual DOM manipulation.

> **Note:** In React, direct DOM APIs (`querySelector`, `createElement`, `appendChild`, etc.) are rarely used. Instead, use **state**, **props**, and **refs (`useRef`)**. Direct DOM access is reserved for tasks like focusing an input, measuring an element, or integrating with third-party libraries.

---

# Common Mistakes

### Manipulating DOM directly inside React

Bad

```js
document.querySelector(".box").style.color = "red";
```

Use state instead.

---

### Using `innerHTML` unnecessarily

```js
div.innerHTML = userInput;
```

Risk:

* XSS attacks
* Performance issues

Prefer:

```js
textContent
```

---

### Forgetting null checks

```js
const btn = document.querySelector(".btn");

btn.click();
```

May throw an error if the element isn't found.

```js
btn?.click();
```

---

### Recreating DOM repeatedly

Bad

```js
for (...) {
    document.createElement(...)
}
```

Better

Create elements in memory (or use a `DocumentFragment`) and append once to reduce reflows.

---

# Best Practices

* Prefer `querySelector()` over older APIs (`getElementById`, etc.) when CSS selectors make code clearer.
* Use `classList` instead of `className`.
* Use `closest()` for event delegation.
* Use `remove()` instead of `removeChild()` when possible.
* Avoid direct DOM manipulation in React; prefer state and refs.
* Cache frequently used DOM references instead of querying repeatedly.
* Check for `null` before operating on elements.

# Frequently Asked Interview Questions (6 Years React)

### 1. What is the DOM?

**Answer:** The DOM is the browser's object representation of an HTML document. It allows JavaScript to read and modify page content, structure, and styles dynamically.

---

### 2. What is the difference between `querySelector()` and `querySelectorAll()`?

**Answer:** `querySelector()` returns the first matching element (or `null`), while `querySelectorAll()` returns a static `NodeList` of all matching elements.

---

### 3. What is the difference between `append()` and `appendChild()`?

**Answer:** `appendChild()` accepts only a single `Node` and returns it. `append()` can accept multiple nodes and strings, making it more flexible.

---

### 4. What does `closest()` do?

**Answer:** It traverses from the current element upward (including itself) and returns the nearest ancestor matching the given selector. It's commonly used in event delegation.

---

### 5. Why should React developers avoid direct DOM manipulation?

**Answer:** React manages the DOM through the Virtual DOM. Directly changing the real DOM can cause inconsistencies between React's virtual representation and the actual UI. Use state, props, or `useRef` instead.

---

### 6. What is `classList` and why is it preferred over `className`?

**Answer:** `classList` provides methods like `add`, `remove`, `toggle`, and `contains` to manipulate individual classes without overwriting existing ones. `className` replaces the entire class string.

---

### 7. What is event delegation and how does `closest()` help?

**Answer:** Event delegation attaches a single event listener to a parent element and handles events from child elements using event bubbling. `closest()` identifies the relevant ancestor associated with the event target.

---

### 8. When would you use direct DOM APIs in React?

**Answer:** Use them sparingly for scenarios such as focusing an input, measuring element size or position, controlling media, or integrating with third-party libraries. Access the DOM via `useRef` rather than global selectors.
