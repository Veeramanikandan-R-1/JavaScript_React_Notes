# JavaScript Numbers — Interview Notes

JavaScript has only one main numeric type: **`Number`**, which uses **IEEE 754 double-precision floating point**.

```js
const a = 10;
const b = 10.5;
```

Also note:

```js
typeof 10; // "number"
```

For integers larger than `Number.MAX_SAFE_INTEGER`, JavaScript provides **`BigInt`**.

---

# 1. `parseInt()` ⭐⭐⭐

Parses a string and returns an **integer**.

```js
parseInt("123px", 10);
// 123
```

The second argument is the **radix** (base). For decimal numbers, use `10`.

```js
parseInt("101", 2);
// 5
```

### Decimal gets truncated

```js
parseInt("10.99", 10);
// 10
```

### Invalid input

```js
parseInt("hello", 10);
// NaN
```

### ⚠️ Important

```js
parseInt("10abc", 10);
// 10
```

It parses until it encounters an invalid character.

---

# 2. `parseFloat()` ⭐⭐

Parses a string and returns a **floating-point number**.

```js
parseFloat("10.50");
// 10.5
```

```js
parseFloat("10.50px");
// 10.5
```

Invalid:

```js
parseFloat("hello");
// NaN
```

### Difference

```js
parseInt("10.99", 10);
// 10

parseFloat("10.99");
// 10.99
```

---

# 3. `Number()` ⭐⭐⭐

Converts a value to a JavaScript `Number`.

```js
Number("123");
// 123

Number("10.5");
// 10.5

Number(true);
// 1

Number(false);
// 0

Number(null);
// 0
```

Invalid conversion:

```js
Number("hello");
// NaN
```

### Important difference ⭐

`Number()` tries to convert the **entire value**:

```js
Number("123px");
// NaN

parseInt("123px", 10);
// 123
```

### Empty string

```js
Number("");
// 0

parseInt("");
// NaN
```

---

# ⭐ `parseInt` vs `parseFloat` vs `Number`

| Input      | `parseInt()` | `parseFloat()` | `Number()` |
| ---------- | -----------: | -------------: | ---------: |
| `"10"`     |         `10` |           `10` |       `10` |
| `"10.5"`   |         `10` |         `10.5` |     `10.5` |
| `"10px"`   |         `10` |           `10` |      `NaN` |
| `"10.5px"` |         `10` |         `10.5` |      `NaN` |
| `""`       |        `NaN` |          `NaN` |        `0` |
| `"hello"`  |        `NaN` |          `NaN` |      `NaN` |

### Interview rule ⭐

```text
parseInt()
→ Parse integer

parseFloat()
→ Parse decimal

Number()
→ Convert entire value to Number
```

# 4. `Math` ⭐⭐⭐

`Math` is a built-in object containing mathematical constants and functions.

It is **not a constructor**.

```js
new Math();
// ❌ TypeError
```

## Common Math methods

### `Math.round()`

Rounds to nearest integer.

```js
Math.round(4.6); // 5
Math.round(4.4); // 4
```

### `Math.floor()`

Rounds **down**.

```js
Math.floor(4.9); // 4
```

### `Math.ceil()`

Rounds **up**.

```js
Math.ceil(4.1); // 5
```

### `Math.trunc()`

Removes decimal portion.

```js
Math.trunc(4.9);  // 4
Math.trunc(-4.9); // -4
```

### ⭐ `floor` vs `trunc`

```js
Math.floor(-4.9); // -5
Math.trunc(-4.9); // -4
```

---

## `Math.max()` / `Math.min()`

Find maximum/minimum.

```js
Math.max(10, 20, 5);
// 20

Math.min(10, 20, 5);
// 5
```

For an array:

```js
const nums = [10, 20, 5];

Math.max(...nums); // 20
Math.min(...nums); // 5
```

---

## `Math.abs()`

Returns absolute value.

```js
Math.abs(-10);
// 10
```

---

## `Math.pow()`

Power calculation.

```js
Math.pow(2, 3);
// 8
```

Modern syntax:

```js
2 ** 3;
// 8
```

---

## `Math.sqrt()`

Square root.

```js
Math.sqrt(16);
// 4
```

---

## `Math.random()` ⭐⭐⭐

Returns a pseudo-random number:

```text
0 <= value < 1
```

```js
Math.random();
// e.g. 0.57382
```

### Random integer from 1–10

```js
const random = Math.floor(Math.random() * 10) + 1;

console.log(random);
```

Formula:

```text
Math.floor(Math.random() * (max - min + 1)) + min
```

Example 5–15:

```js
const random =
  Math.floor(Math.random() * 11) + 5;
```

⚠️ `Math.random()` is **not cryptographically secure**. Don't use it for passwords, tokens, security-sensitive IDs, etc.

# ⭐ Special Number Values

Very important for interviews:

```js
Number.isNaN(NaN);
// true

Number.isFinite(10);
// true

Number.isFinite(Infinity);
// false

Number.isInteger(10);
// true

Number.isInteger(10.5);
// false
```

### `NaN`

`NaN` means **Not-a-Number**, but its type is still:

```js
typeof NaN;
// "number"
```

And:

```js
NaN === NaN;
// false
```

Use:

```js
Number.isNaN(value);
```

---

# ⚠️ Floating-Point Precision

JavaScript numbers use floating-point representation.

Therefore:

```js
0.1 + 0.2 === 0.3;
// false
```

Because of floating-point precision.

For typical UI calculations, rounding may be needed:

```js
const result = Number((0.1 + 0.2).toFixed(2));

console.log(result);
// 0.3
```

For financial/precision-critical calculations, don't blindly rely on floating-point arithmetic.

# 🎯 Quick Revision

```text
parseInt()
→ String → integer
→ parseInt("10px", 10) → 10

parseFloat()
→ String → decimal
→ parseFloat("10.5px") → 10.5

Number()
→ Convert entire value
→ Number("10.5") → 10.5

Math
→ Mathematical operations

round() → nearest
floor() → down
ceil()  → up
trunc() → remove decimal
max()   → largest
min()   → smallest
abs()   → absolute
random() → 0 to <1
```

### ⭐ Most important interview points

1. **Always specify radix with `parseInt(value, 10)`.**
2. `parseInt("123px")` → `123`, while `Number("123px")` → `NaN`.
3. `Math.floor()` and `Math.trunc()` differ for negative numbers.
4. JavaScript `Number` uses **IEEE 754 double precision**, causing floating-point precision issues.
5. Use `Number.isNaN()` / `Number.isFinite()` for reliable numeric checks.
