# JavaScript Objects

Objects are the **most important data structure in JavaScript**. Almost everything in React revolves around objects:

* Props
* State
* API responses
* Configuration
* Context values
* Redux store
* Component options

Understanding objects is critical because React depends on **object references** for rendering and performance.

---

# What is an Object?

An object is a collection of **key-value pairs**.

```javascript
const user = {
    name: "John",
    age: 30
};
```

Here,

```text
Key      Value
----------------
name  →  John
age   →  30
```

---

# Why Objects?

Instead of storing related values separately,

❌

```javascript
const name = "John";
const age = 30;
const city = "London";
```

We group them together.

✅

```javascript
const user = {
    name: "John",
    age: 30,
    city: "London"
};
```

This makes data easier to manage.


---

# 1. Object Creation

There are multiple ways to create objects.

---

## Method 1: Object Literal (Most Common)

```javascript
const user = {
    name: "John",
    age: 30
};
```

Used in almost every React application.

---

## Method 2: Object Constructor

```javascript
const user = new Object();

user.name = "John";
user.age = 30;
```

Rarely used.

---

## Method 3: Object.create()

Creates an object with a specified prototype.

```javascript
const person = {
    greet() {
        console.log("Hello");
    }
};

const user = Object.create(person);

user.name = "John";

user.greet();
```

---

## Method 4: Constructor Function

```javascript
function User(name, age) {
    this.name = name;
    this.age = age;
}

const user = new User("John", 30);
```

Older JavaScript style (before ES6 classes).

---

## Method 5: Class (ES6)

```javascript
class User {
    constructor(name) {
        this.name = name;
    }
}

const user = new User("John");
```

Common in OOP code.

---

# 2. Object Destructuring

Destructuring extracts properties into variables.

Instead of

```javascript
const name = user.name;
const age = user.age;
```

Use

```javascript
const { name, age } = user;
```

---

## Example

```javascript
const user = {
    name: "John",
    age: 30
};

const { name, age } = user;

console.log(name);
console.log(age);
```

---

## Rename Variables

```javascript
const {
    name: username
} = user;

console.log(username);
```

---

## Default Values

```javascript
const user = {
    name: "John"
};

const {
    age = 25
} = user;

console.log(age);
```

Output

```text
25
```

---

## Nested Destructuring

```javascript
const user = {
    address: {
        city: "London"
    }
};

const {
    address: {
        city
    }
} = user;

console.log(city);
```

---

## React Example

```jsx
function User({ name, age }) {
    return (
        <>
            {name}
            {age}
        </>
    );
}
```

Instead of

```jsx
function User(props) {
    return props.name;
}
```

# 3. Object.freeze()

Makes an object **completely immutable** (shallow).

After freezing,

* Cannot add properties
* Cannot delete properties
* Cannot modify existing properties

---

Example

```javascript
const user = {
    name: "John"
};

Object.freeze(user);

user.name = "David";

console.log(user.name);
```

Output

```text
John
```

---

## Cannot Add

```javascript
user.age = 30;
```

Ignored (or throws in strict mode).

---

## Cannot Delete

```javascript
delete user.name;
```

Ignored.

---

## Important

`freeze()` is **shallow**.

```javascript
const user = {
    address: {
        city: "London"
    }
};

Object.freeze(user);

user.address.city = "Paris";
```

Output

```text
Paris
```

Nested objects are still mutable.

---

# 4. Object.seal()

Sealing is less strict than freezing.

After sealing,

✅ Existing properties can be modified.

❌ New properties cannot be added.

❌ Existing properties cannot be deleted.

---

Example

```javascript
const user = {
    name: "John"
};

Object.seal(user);

user.name = "David";

console.log(user.name);
```

Output

```text
David
```

---

Adding

```javascript
user.age = 30;
```

Ignored.

Deleting

```javascript
delete user.name;
```

Ignored.

---

# Freeze vs Seal

| Feature         | Freeze | Seal |
| --------------- | ------ | ---- |
| Modify existing | ❌      | ✅    |
| Add property    | ❌      | ❌    |
| Delete property | ❌      | ❌    |

---

# 5. Object.assign()

Copies properties from one or more objects.

Syntax

```javascript
Object.assign(target, source);
```

---

## Merge Objects

```javascript
const obj1 = {
    a: 1
};

const obj2 = {
    b: 2
};

const result =
Object.assign({}, obj1, obj2);

console.log(result);
```

Output

```javascript
{
    a:1,
    b:2
}
```

---

## Clone Object

```javascript
const copy =
Object.assign({}, user);
```

Creates a **shallow copy**.

---

## React Example

Before spread operator became common:

```javascript
const updated =
Object.assign({}, user, {
    age: 31
});
```

Today, most developers use:

```javascript
const updated = {
    ...user,
    age: 31
};
```

---

# Assign is Shallow

```javascript
const user = {
    address: {
        city: "London"
    }
};

const copy =
Object.assign({}, user);

copy.address.city = "Paris";
```

Original also changes because nested objects share references.

---

# 6. Object.entries()

Returns an array of `[key, value]` pairs.

Example

```javascript
const user = {
    name: "John",
    age: 30
};

console.log(Object.entries(user));
```

Output

```javascript
[
  ["name","John"],
  ["age",30]
]
```

---

## Loop Example

```javascript
for (const [key, value] of Object.entries(user)) {
    console.log(key, value);
}
```

Output

```text
name John
age 30
```

---

# 7. Object.keys()

Returns all property names.

```javascript
console.log(Object.keys(user));
```

Output

```javascript
["name", "age"]
```

---

## React Example

Rendering dynamic fields.

```jsx
Object.keys(user).map(key => (
    <p key={key}>
        {key}
    </p>
));
```

---

# 8. Object.values()

Returns all property values.

```javascript
console.log(Object.values(user));
```

Output

```javascript
["John", 30]
```

---

## Example

```javascript
const prices = {
    apple: 10,
    mango: 20,
    orange: 30
};

const total =
Object.values(prices)
    .reduce((sum, price) => sum + price, 0);

console.log(total);
```

Output

```text
60
```

---

# keys() vs values() vs entries()

```javascript
const user = {
    name: "John",
    age: 30
};
```

| Method                 | Output                         |
| ---------------------- | ------------------------------ |
| `Object.keys(user)`    | `["name", "age"]`              |
| `Object.values(user)`  | `["John", 30]`                 |
| `Object.entries(user)` | `[["name","John"],["age",30]]` |

# Common Mistakes

### ❌ Assuming `freeze()` freezes nested objects

It only freezes the first level.

---

### ❌ Assuming `Object.assign()` performs a deep copy

It creates only a **shallow copy**.

---

### ❌ Forgetting Default Values in Destructuring

```javascript
const { age = 18 } = user;
```

Useful when a property may be missing.

---

### ❌ Mutating React State

```javascript
user.age = 30;
```

Instead

```javascript
setUser({
    ...user,
    age: 30
});
```

---

### ❌ Confusing `keys()`, `values()`, and `entries()`

Remember:

* `keys()` → Property names
* `values()` → Property values
* `entries()` → `[key, value]` pairs

---

# Best Practices

* Prefer object literals (`{}`) for creating objects.
* Use destructuring to make code cleaner.
* Use spread (`...`) or `Object.assign()` for immutable updates.
* Use `Object.keys()`, `Object.values()`, and `Object.entries()` for iteration.
* Use `Object.freeze()` for constants or configuration objects that should not change.
* Remember that `freeze()` and `Object.assign()` are **shallow** operations.

# Common React (6 Years Experience) Interview Questions

### 1. What are the different ways to create an object in JavaScript?

**Answer:**

* Object literal (`{}`)
* `new Object()`
* `Object.create()`
* Constructor function
* ES6 class

---

### 2. What is object destructuring?

**Answer:**
Object destructuring extracts object properties into variables using a concise syntax.

```javascript
const { name, age } = user;
```

---

### 3. What is the difference between `Object.freeze()` and `Object.seal()`?

| `freeze()`                        | `seal()`                            |
| --------------------------------- | ----------------------------------- |
| Cannot modify existing properties | Existing properties can be modified |
| Cannot add properties             | Cannot add properties               |
| Cannot delete properties          | Cannot delete properties            |
| Shallow                           | Shallow                             |

---

### 4. Is `Object.freeze()` a deep freeze?

**Answer:**
No. It only freezes the top-level object. Nested objects remain mutable unless they are frozen separately.

---

### 5. What does `Object.assign()` do?

**Answer:**
It copies enumerable own properties from one or more source objects into a target object. It is commonly used for merging objects or creating a shallow copy.

---

### 6. What is the difference between `Object.assign()` and the spread operator?

**Answer:**
Both create **shallow copies** and merge objects. The spread operator (`{ ...obj }`) is generally preferred in modern JavaScript because it is more concise and widely used in React state updates.

---

### 7. What is the difference between `Object.keys()`, `Object.values()`, and `Object.entries()`?

**Answer:**

* `Object.keys()` → Returns an array of property names.
* `Object.values()` → Returns an array of property values.
* `Object.entries()` → Returns an array of `[key, value]` pairs.

---

### 8. Why is immutability important when working with React state?

**Answer:**
React compares object references to detect changes. Instead of mutating an existing object, create a new object using the spread operator or `Object.assign()` so React can detect the update and re-render efficiently.
