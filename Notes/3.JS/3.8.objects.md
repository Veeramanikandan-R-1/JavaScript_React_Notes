# JavaScript Objects — Interview Notes

Objects store data as **key-value pairs** and are one of the most commonly used data structures in React/JavaScript.

---

## 1. Object Creation ⭐

### Object literal — most common

```js
const user = {
  name: "John",
  age: 30
};
```

### `new Object()`

```js
const user = new Object();

user.name = "John";
```

Usually prefer **object literals**.

### `Object.create()`

Creates an object with a specified prototype.

```js
const person = {
  greet() {
    console.log("Hello");
  }
};

const user = Object.create(person);

user.greet(); // Hello
```

Here `user` inherits from `person`.

---

# 2. Destructuring ⭐⭐⭐

Extract values from objects into variables.

```js
const user = {
  name: "John",
  age: 30
};

const { name, age } = user;

console.log(name); // John
console.log(age);  // 30
```

### Rename

```js
const { name: userName } = user;

console.log(userName); // John
```

### Default value

```js
const { city = "Chennai" } = user;
```

### Nested destructuring

```js
const user = {
  profile: {
    name: "John"
  }
};

const {
  profile: { name }
} = user;
```

### React ⭐

Very commonly used with props:

```jsx
function User({ name, age }) {
  return <h2>{name} - {age}</h2>;
}
```

---

# 3. `Object.freeze()` ⭐⭐

Makes an object **immutable at the top level**.

```js
const user = {
  name: "John",
  age: 30
};

Object.freeze(user);

user.name = "Bob"; // ❌ Cannot modify
user.age = 40;     // ❌ Cannot modify
```

Also prevents:

* Adding properties
* Removing properties
* Modifying existing properties

### ⚠️ Shallow

`freeze()` is **shallow**:

```js
const user = {
  name: "John",
  address: {
    city: "Chennai"
  }
};

Object.freeze(user);

user.address.city = "Madurai"; // ✅ Can change
```

Because `address` is a nested object.

---

# 4. `Object.seal()` ⭐⭐

Prevents:

* Adding properties
* Removing properties

But **existing properties can still be modified**.

```js
const user = {
  name: "John",
  age: 30
};

Object.seal(user);

user.name = "Bob"; // ✅
user.city = "Chennai"; // ❌
delete user.age;      // ❌
```

### Freeze vs Seal

| `freeze()` | `seal()` |
| ---------- | -------- |
| Add ❌      | Add ❌    |
| Delete ❌   | Delete ❌ |
| Modify ❌   | Modify ✅ |
| Shallow    | Shallow  |

---

# 5. `Object.assign()` ⭐⭐⭐

Copies properties from one or more source objects into a target object.

```js
const user = {
  name: "John"
};

const details = {
  age: 30
};

Object.assign(user, details);

console.log(user);
// { name: "John", age: 30 }
```

### Create a new object ⭐

```js
const updatedUser = Object.assign({}, user, {
  age: 31
});
```

This is conceptually similar to:

```js
const updatedUser = {
  ...user,
  age: 31
};
```

### ⚠️ Shallow copy

Like spread, `Object.assign()` performs a **shallow copy**.

---

# 6. `Object.entries()` ⭐⭐

Returns an array of `[key, value]` pairs.

```js
const user = {
  name: "John",
  age: 30
};

console.log(Object.entries(user));
```

Result:

```js
[
  ["name", "John"],
  ["age", 30]
]
```

### Useful for iteration

```js
Object.entries(user).forEach(([key, value]) => {
  console.log(key, value);
});
```

---

# 7. `Object.keys()` ⭐⭐

Returns an array containing the object's **own enumerable property names**.

```js
const user = {
  name: "John",
  age: 30
};

console.log(Object.keys(user));

// ["name", "age"]
```

### Count properties

```js
Object.keys(user).length; // 2
```

---

# 8. `Object.values()` ⭐⭐

Returns an array containing the object's **own enumerable property values**.

```js
const user = {
  name: "John",
  age: 30
};

console.log(Object.values(user));

// ["John", 30]
```

### Example

```js
const prices = {
  product1: 100,
  product2: 200,
  product3: 300
};

const total = Object.values(prices)
  .reduce((sum, price) => sum + price, 0);

console.log(total); // 600
```

---

# ⭐ Keys vs Values vs Entries

Given:

```js
const user = {
  name: "John",
  age: 30
};
```

### `Object.keys()`

```js
["name", "age"]
```

### `Object.values()`

```js
["John", 30]
```

### `Object.entries()`

```js
[
  ["name", "John"],
  ["age", 30]
]
```

Easy to remember:

```text
keys    → keys
values  → values
entries → [key, value]
```

# ⭐ Important React Usage

### Immutable update

```js
setUser(prev => ({
  ...prev,
  name: "Bob"
}));
```

### Destructuring props

```jsx
function Profile({ name, email }) {
  return <div>{name} - {email}</div>;
}
```

### Iterate object

```jsx
Object.entries(user).map(([key, value]) => (
  <p key={key}>
    {key}: {value}
  </p>
));
```

# 🎯 Quick Interview Revision

```text
Object creation
→ {} / Object.create() / new Object()

Destructuring
→ Extract properties into variables

Object.freeze()
→ No add/delete/modify
→ Shallow

Object.seal()
→ No add/delete
→ Existing properties can be modified
→ Shallow

Object.assign()
→ Copy/merge objects
→ Shallow

Object.keys()
→ Array of keys

Object.values()
→ Array of values

Object.entries()
→ Array of [key, value]
```

### ⭐ Most important interview points

> **`Object.freeze()` vs `Object.seal()`** — freeze prevents modification; seal allows modification of existing properties.

> **`Object.assign()` and spread (`...`) perform shallow copies**, not deep copies.

> `Object.keys()`, `Object.values()`, and `Object.entries()` operate on an object's **own enumerable properties**.
