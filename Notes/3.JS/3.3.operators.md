# JavaScript Operators — Interview Notes

These operators are especially important in modern React development.

---

# 1. Equality Operators ⭐⭐⭐

JavaScript has two main equality operators:

### `===` — Strict Equality

Checks **value + type** without type coercion.

```js
5 === 5       // true
5 === "5"     // false
true === 1    // false
null === undefined // false
```

### `==` — Loose Equality

Allows **type coercion** before comparison.

```js
5 == "5"      // true
true == 1     // true
null == undefined // true
```

### Best practice ⭐

Prefer:

```js
a === b
a !== b
```

Avoid `==` unless you intentionally need its coercion behavior.

### Interview question

```js
0 == false   // true
0 === false  // false
```

Because `==` converts types, while `===` does not.

# 2. Nullish Coalescing `??` ⭐

Returns the right-hand value only when the left-hand value is:

```text
null
undefined
```

```js
const name = null ?? "Guest";

console.log(name); // "Guest"
```

### Important difference from `||`

`||` treats **all falsy values** as missing:

```js
0
""
false
null
undefined
NaN
```

But `??` only checks:

```js
null
undefined
```

Example:

```js
const count = 0;

console.log(count || 10); // 10
console.log(count ?? 10); // 0
```

### React example

```js
const pageSize = user.pageSize ?? 10;
```

If `pageSize` is `0`, it remains `0`.

### ⚠️ Important

Don't mix `??` with `||` or `&&` without parentheses:

```js
// ❌ SyntaxError
a ?? b || c
```

Use:

```js
(a ?? b) || c
```

# 3. Optional Chaining `?.` ⭐⭐⭐

Safely accesses nested properties without throwing an error when an intermediate value is `null` or `undefined`.

Without optional chaining:

```js
const city = user && user.address && user.address.city;
```

With:

```js
const city = user?.address?.city;
```

If `user` or `address` is `null`/`undefined`:

```text
city → undefined
```

instead of:

```text
TypeError
```

### Function call

```js
user?.getName?.();
```

Calls `getName()` only if it exists and is callable.

### Array access

```js
users?.[0]?.name;
```

### React example ⭐

```jsx
function User({ user }) {
  return <h2>{user?.profile?.name ?? "Guest"}</h2>;
}
```

Here:

```text
?. → safely access
?? → provide fallback
```

# 4. Spread Operator `...` ⭐⭐⭐

Spread **expands** elements/properties from an iterable or object.

### Array

```js
const a = [1, 2];
const b = [3, 4];

const result = [...a, ...b];

console.log(result);
// [1, 2, 3, 4]
```

### Object

```js
const user = {
  name: "John",
  age: 30
};

const updatedUser = {
  ...user,
  age: 31
};
```

Result:

```js
{
  name: "John",
  age: 31
}
```

If duplicate properties exist, the **later property wins**:

```js
const user = {
  ...oldUser,
  name: "Bob"
};
```

### React ⭐

Very commonly used for immutable state updates:

```js
setUser(prev => ({
  ...prev,
  name: "Bob"
}));
```

Array:

```js
setItems(prev => [...prev, newItem]);
```

### ⚠️ Shallow copy

Spread performs a **shallow copy**.

```js
const user2 = { ...user };
```

Nested objects are still shared references:

```js
user2.address === user.address; // true
```

# 5. Rest Operator `...` ⭐⭐⭐

Rest **collects multiple values into a single array/object**.

It looks exactly like spread, but the purpose is opposite.

### Function parameters

```js
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

sum(1, 2, 3, 4); // 10
```

`...numbers` collects arguments:

```text
1, 2, 3, 4
      ↓
[1, 2, 3, 4]
```

### Destructuring

```js
const user = {
  name: "John",
  age: 30,
  city: "Chennai"
};

const { name, ...otherDetails } = user;

console.log(name);
// John

console.log(otherDetails);
// { age: 30, city: "Chennai" }
```

### React Props ⭐

```jsx
function User({ name, ...props }) {
  return <input {...props} />;
}
```

Usage:

```jsx
<User
  name="John"
  type="text"
  placeholder="Enter name"
/>
```

`...props` collects the remaining props.

---

# ⭐ Spread vs Rest

Same syntax:

```js
...
```

But context determines the meaning.

| Spread                                  | Rest                             |
| --------------------------------------- | -------------------------------- |
| Expands values                          | Collects values                  |
| Used when creating arrays/objects/calls | Used in parameters/destructuring |
| `[...arr]`                              | `function fn(...args)`           |
| `{...user}`                             | `const {name, ...rest}`          |

### Easy way to remember

```text
Spread → Spread OUT
Rest   → Gather the REST
```

# 🎯 Quick Interview Revision

```text
=== 
→ Strict equality, no type coercion

??
→ Fallback only for null/undefined

?.
→ Safely access nested values

...
→ Spread → expand
→ Rest   → collect
```

### ⭐ Common React combination

```jsx
function Profile({ user }) {
  const name = user?.profile?.name ?? "Guest";

  return (
    <div>
      <h2>{name}</h2>
    </div>
  );
}
```

And immutable state updates:

```js
setUser(prev => ({
  ...prev,
  profile: {
    ...prev.profile,
    name: "John"
  }
}));
```

**Interview takeaway:** `===`, `??`, `?.`, spread/rest are fundamental modern JavaScript features you'll frequently use in React for **safe data access, defaults, immutable updates, prop handling, and function parameters**.
