# AI Tools, Workflow, and Design

AI can speed up frontend work, but the developer still owns correctness, accessibility, design quality, and maintainability.

---

# 1. AI Coding Tools

Useful tools to explore:

* GitHub Copilot
* Cursor
* Codeium
* ChatGPT

Use them for:

* Explaining unfamiliar code
* Generating first drafts
* Writing tests
* Refactoring small functions
* Creating checklists
* Reviewing accessibility and edge cases

Do not use them blindly. Always review generated code.

---

# 2. AI UI Generation Tools

Tools and workflows:

* Figma to code
* v0.dev
* Galileo AI
* AI-generated wireframes
* AI-generated component ideas

Use these for inspiration, not final production code without review.

Review for:

* Semantic HTML
* Responsive layout
* Accessibility
* Reusable components
* Real content handling
* Design consistency

---

# 3. Tailwind CSS in AI-Ready Frontend Work

Tailwind is useful for fast UI building, especially with AI-generated component drafts.

Practice:

* Build a responsive navbar.
* Build a card grid.
* Build a dashboard shell.
* Build a chat layout.
* Refactor repeated class groups into components.

Watch for:

* Very long class strings
* Inconsistent spacing
* Missing focus styles
* Poor mobile layout
* One-off styling everywhere

---

# 4. Framer Motion

Use Framer Motion for portfolio polish or carefully designed product motion.

Good uses:

* Page transitions
* Small entrance animations
* Expand/collapse interactions
* Feedback after user actions

Avoid:

* Motion that slows the interface
* Motion that distracts from content
* Ignoring reduced-motion preference

---

# 5. AI-Assisted Development Workflow

Use this workflow:

```text
1. Write requirement yourself.
2. Ask AI for possible approach.
3. Build small version manually.
4. Ask AI to review edge cases.
5. Add tests.
6. Check accessibility.
7. Check performance.
8. Refactor only if needed.
```

---

# 6. Soft Skills and Mindset

AI can generate code, but it cannot replace:

* Clear communication
* Product thinking
* Code review quality
* Debugging judgment
* Understanding business context
* Taste in UI and UX

Practical rule:

```text
AI can help write code faster.
You are responsible for whether the code should exist.
```
